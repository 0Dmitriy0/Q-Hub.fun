# Q-Hub.fun

**Неофіційний фан-проєкт для гравців QuantRP (GTA V RP).** Два продукти: сайт [q-hub.fun](https://q-hub.fun) і програма Q-Hub для Windows, яка працює поверх гри. Робить сім'я CORE.

Акаунт один на обидва — вхід через Discord.

---

## Сайт — [q-hub.fun](https://q-hub.fun)

Відкривається в будь-якому браузері, з телефона теж. Більшість розділів працює без входу.

| Розділ | Що там |
|---|---|
| [**Ціни**](https://q-hub.fun/tsiny) | Ціни всіх скупників: хто зараз платить більше, межі цін, коли зміниться ціна, історія й калькулятор. Ціни вносять самі гравці. Поточною ціна стає, коли однакову внесли кілька різних людей. |
| [**Мапа**](https://q-hub.fun/mapa) | Мапа штату: магазини, роботи, скупники, банди, зелені зони, сезонні мітки. Можна зробити скрін мапи з потрібними мітками (PNG або SVG). Є [інструкція](https://q-hub.fun/mapa/v-gru), як поставити цю мапу прямо в GTA V. |
| [**WIKI → Роботи**](https://q-hub.fun/wiki/roboty) | Усі роботи: з якого рівня, де влаштуватися, оплата, рівні навички, точка на мапі. |
| [**WIKI → Транспорт**](https://q-hub.fun/wiki/transport) | Ціни в салоні, характеристики, калькулятор тюнінгу, оцінки гравців. |
| [**WIKI → Івенти**](https://q-hub.fun/wiki/iventy) | Розклад щогодинних івентів, сезонні події (з архівом минулих) і промокоди. |
| [**Кабінет**](https://q-hub.fun/kabinet) | Твій заробіток, документи й правки. Бачиш лише ти. На сайті — для перегляду, змінюються дані в програмі. |

Довідник наповнюють гравці: пропонують правки, а редактори їх перевіряють і публікують.

## Програма Q-Hub для Windows

[**Завантажити інсталятор**](https://github.com/0Dmitriy0/Q-Hub.fun/releases/download/desktop-latest/Q-Hub-Setup.exe) · [Інструкція](https://q-hub.fun/programa/instruktsiya)

Програма — це рядок поверх гри: **Alt+Q** відкриває, ще раз — ховає.

- **Пошук у правилах і законах.** Звичайними словами, сленгом («дм», «капт») або номером статті («КК 1.8»). Без ліміту.
- **Питання до ШІ** (Shift+Enter). Відповідає з правил сервера й показує пункт, з якого взяв відповідь. 50 питань на день.
- **Ціни скупників** (Tab). Ті самі, що на сайті.
- **Мапа поверх гри** (Alt+M). Показує «Ти тут»; можна запропонувати нову мітку або позначити застарілу.
- **Мітка з гри** (Alt+F9). Відкрий карту гри на потрібному місці — програма сама знайде точку й відправить мітку на перевірку модератору.
- **Облік заробітку.** Програма читає з екрана готівку й картку і рахує, скільки ти заробляєш за годину. Підсумок сесії видно в кабінеті.
- **Ціни з вікна скупника.** За бажанням програма сама вносить ціни, коли ти відкриваєш вікно скупника.
- **Оновлюється сама**, у фоні.

**Що потрібно:** Windows 10 або 11 (64-біт) і GTA V у режимі «Вікно без рамки» (Borderless). Windows може попередити «Захистив ваш ПК», бо інсталятор ще не підписаний. Тоді натисни «Докладніше» → «Виконати все одно».

**Безпечно для акаунта гри.** Програма лише робить знімки екрана, як OBS. Вона не читає пам'ять гри й нічого в ній не натискає.

Версії 0.x — тестові, програма ще в розробці. Що змінилось — у програмі: Налаштування → Журнал оновлень.

## Приватність

- Облік, заробіток і документи бачиш лише ти. Це захищено правилами самої бази, а не тільки інтерфейсом.
- Знімки з мітками бачить лише модератор, який їх перевіряє.
- Пароль від Discord сайт і програма не отримують: вхід іде через сторінку Discord.

## Зв'язок

Питання, помилки й ідеї — у Discord Q-Hub. Посилання є внизу будь-якої сторінки сайту.

## Для розробників

- **Сайт:** Vite + React + TypeScript. **База:** Supabase (PostgreSQL, Row Level Security, вхід через Discord). **Програма:** Electron.
- Налаштування бази, входу й автодеплою — [docs/SETUP.md](docs/SETUP.md). План — [docs/PLAN.md](docs/PLAN.md). Специфікації функцій — у [`specs/`](specs).
- Push у `main` збирає й тестує сайт, а потім викладає його на хостинг. Зміни програми збирають інсталятор у [Releases](https://github.com/0Dmitriy0/Q-Hub.fun/releases).

```
npm install
npm test                      # тести сайту
npm run build                 # збірка → dist/
bash supabase/tests/run.sh    # правила доступу бази (локальний PostgreSQL)
cd desktop && npm install && npm start   # програма локально
```

Q-Hub не пов'язаний з адміністрацією QuantRP. Назви й матеріали гри належать їхнім власникам.
