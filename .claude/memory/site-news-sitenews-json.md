З 2026-11-05 (specs/060 US2) новини Q-Hub ідуть у Discord через чернетки в адмінці → «Новини».
- Зміна програми — як і раніше, запис у `src/data/changelog.json` (див. [[changelog-program-only]]).
- Зміна лише сайту, помітна гравцю — запис у `src/data/sitenews.json` (той самий формат: `id` — дата, `title`, `added / changed / fixed`, мовою гравця). Той самий день, запис ще не в `main` — доповнювати; уже в `main` — новий `id` `РРРР-ММ-ДД.2`, бо чернетка створюється раз за `source_ref` (`site:<id>`) і дописане в наявний запис у неї не потрапить.
- Після деплою з `main` крок «Discord news drafts» у `deploy.yml` шле верхні записи обох файлів у функцію `discord-bot` (дія `drafts`). Нічого не публікує: надсилає лише адмін кнопкою (дія `send`, ключ `news:<id>` — без дублів).

**Why:** власник хоче публікувати новини сайту й програми в Discord, але лише після перегляду (рішення 2026-11-04).

**How to apply:** у кожній гілці зі зміною сайту для гравців — рядок у `sitenews.json`; внутрішні зміни (адмінка, CI, рефакторинг) — не вписувати.
