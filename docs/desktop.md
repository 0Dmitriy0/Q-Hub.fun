# Q-Hub Desktop — план

Програма поверх гри для Windows: `Alt+Q` — пошук ціни; баланс з екрана → облік персонажа на сайті.
Код — `desktop/` (Electron). Збирає GitHub Actions (`.github/workflows/desktop.yml`, Windows-інсталятор).

## Вхід (вирішено)

Власна сесія програми, не спільна з браузером: Supabase видає одноразові refresh-токени — спільна сесія
викидала б з акаунта то сайт, то програму.

1. «Увійти через Discord» → програма піднімає сервер на `http://127.0.0.1:53682` (запасний — 53683)
   і відкриває системний браузер: Supabase OAuth (Discord), PKCE, `redirectTo = http://127.0.0.1:<порт>/auth`.
2. Після входу браузер приходить на `/auth?code=…`; програма міняє код на сесію (`exchangeCodeForSession`)
   і показує в браузері «Готово, повертайся в програму».
3. Сесія — у `userData/session.bin`, зашифрована `safeStorage` (Windows DPAPI). Токени оновлюються самі.
4. «Вийти» — `signOut` (сесія програми анулюється на сервері; сайт не чіпається).

Права — як у гравця на сайті (anon-ключ + JWT гравця, RLS): лише свої персонажі й облік.
**Налаштування Supabase (робить власник):** Authentication → URL Configuration → Redirect URLs — додати
`http://127.0.0.1:53682/auth` і `http://127.0.0.1:53683/auth`.

## Кабінет — у програмі, на сайті — перегляд (рішення власника, 22.10)

- «Відкрити кабінет» відкриває `https://q-hub.fun/kabinet` у вікні програми (1280×820). Сторінки сайту — у програмі,
  інші адреси — у браузері. Зміни кабінету приходять разом із деплоєм сайту, без перевстановлення програми.
- Сесією володіє програма: сторінка отримує токени через міст (`window.qhub.session/onSession`, `src/lib/app.ts`),
  сама їх не оновлює й не зберігає (інакше одноразовий refresh-токен використовувався б двічі). «Вийти» в кабінеті —
  вихід із програми.
- У браузері кабінет лише для перегляду: `fieldset disabled`, форми додавання й «Скинути дані» сховано (`.ro`).
  Це обмеження інтерфейсу, не бази: RLS дозволяє гравцю писати свої рядки звідусіль (і має — програма ходить тим самим ключем).

## Синхронізація

- Облік: програма лише **додає** записи (`transactions.source = 'desktop'`), нічого не змінює й не видаляє —
  конфліктів із сайтом немає. Без інтернету — черга в `userData/queue.json`, відправка при появі зв'язку;
  `external_id` (uuid запису) не дає задублювати при повторі.
- Ціни для `Alt+Q`: читає з бази (публічні), кеш на диску, оновлення раз на кілька хвилин.
