# Знімки великої карти для тестів зіставлення (`mapmatch.test.cjs`)

Кожен знімок — пара файлів з однаковою назвою:

- `<назва>.png` — повний знімок екрана гри з відкритою великою картою;
- `<назва>.json` — де насправді стоїть гравець:

```json
{ "x": -430.5, "y": 1120.0, "scale_m": 551, "note": "Західний Вайнвуд, біля обсерваторії" }
```

`x`, `y` — метри гри, як показує мапа Q-Hub під курсором; `scale_m` — число на шкалі внизу ліворуч.

Правила (конституція, принцип III):

- лише **власні** знімки: без чату, ніків і чужих міток;
- знімки від тестувальників сюди не кладемо — вони лишаються в закритому сховищі;
- у інсталятор тека не потрапляє (`!src/fixtures/**` у `desktop/package.json`).

Потрібно 20+ знімків біля відомих міток: масштаби 100–1000 м, різні райони, щонайменше один — з нестандартною палітрою карти (T033).
