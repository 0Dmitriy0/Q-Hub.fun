# Знімки великої карти для тестів зіставлення (`mapmatch.test.cjs`)

Кожен знімок — пара файлів з однаковою назвою:

- `<назва>.png` — повний знімок екрана гри 1920×1080 з відкритою великою картою;
- `<назва>.json` — що насправді під хрестиком у центрі екрана:

```json
{ "x": -430.5, "y": 1120.0, "scale_m": 551, "note": "Західний Вайнвуд, біля обсерваторії" }
```

`x`, `y` — метри гри, як показує мапа Q-Hub під курсором; `scale_m` — число на шкалі внизу ліворуч; `note` — звідки взято точку.

Як знімати (2026-10-26):

- звичайний скрін **Win + PrtScn**, не F9 (F9 стискає в JPEG);
- хрестик — на мітці: або карту відкрито там, де стоїш, або мітку вибрано стрілками («Выбрать метку»);
- на одному місці — 3–4 масштаби: 60–100 м (з нього рахується точка), ~300, ~600, ~1000 м; ближче за 50 м програма не працює;
- точка: мітка Q-Hub + зсув її значка від хрестика на близькому кадрі; немає мітки — накладення еталона (див. `note`).
  Мітки в базі бувають зсунуті на 10–16 м від значка в грі (Нацгвардія) — тоді береться значок.
- кольори округлено до кроку 8 (удвічі менші файли; результат зіставлення той самий).

Правила (конституція, принцип III):

- лише **власні** знімки: без чату, ніків і чужих міток; свій персонаж чи авто в кадрі — можна;
- знімки від тестувальників сюди не кладемо — вони лишаються в закритому сховищі;
- у інсталятор тека не потрапляє (`!src/fixtures/**` у `desktop/package.json`).
