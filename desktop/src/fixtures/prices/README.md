# Записи прокручування вікон скупників (specs/024)

Тут лежать **розпізнаний текст** кадрів вікна скупника — не знімки (конституція, принцип III: на знімках бувають чат
і ніки інших гравців). Тест — `src/lib/priceFixtures.test.ts` (vitest сайту: тести програми йдуть до збірки, а
`lib/shotparse.cjs` з'являється лише після неї).

## Формат

```json
{
  "buyer": "hide",
  "note": "повне прокручування згори донизу, 1920×1080, 2026-10-29",
  "items": [{ "id": 1, "name": "Шкура оленя", "min": 300, "max": 800 }],
  "expect": { "1": 485 },
  "unsure": [],
  "log": { "cover": [32, 32, 0], "sent": [[1, 485]] },
  "frames": [
    { "t": 0, "lines": [{ "text": "Шкура оленя", "y": 412, "x": 1210, "h": 38, "col": 1 }, { "text": "~", "y": 450, "x": 1210, "h": 20, "col": 1 }] },
    { "t": 4100, "lines": [] }
  ]
}
```

- `items` — товари скупника з межами цін на день запису (каталог Q-Hub змінюється, запис — ні);
- `frames` — кадри по порядку: `t` — мс від першого кадру (від нього залежить «відкриття вікна»), `lines` — рядки так,
  як їх повертає `lines()` у `vision.cjs`. Рядки без кирилиці (фон гри, імена латиницею) і рядки з робочого столу
  мають текст `~`: висота й місце лишаються, бо від медіани висоти залежить, які рядки `parseShot` відкидає;
- `expect` — ціни (`item_id → ціна`), які має надіслати програма; тест перевіряє, що жодна надіслана ціна від них не
  відрізняється й не виходить за межі товару;
- `unsure` — товари, зчитки яких розходяться (еталону немає): тест перевіряє для них лише межі;
- `log` — що програма показала й надіслала тоді, на живій грі (для порівняння; там є й хибні ціни, як-от 5546).

## Що є

| Файл | Кадрів | Що перевіряє |
|---|---|---|
| `hide-full.json` | 12 | «Шкури» прокручено згори донизу — 32 з 32 |
| `hide-partial.json` | 2 | ті самі «Шкури» до прокручування — менше 32 |
| `junk-full.json` | 61 | «Мотлох» туди й назад |
| `junk-fast.json` | 10 | «Мотлох», швидке прокручування — ті самі ціни, що й повне |
| `fish-full.json` | 26 | «Риба»: «Фугу» OCR не впізнає (T030), «Акула» — `unsure` (164 чи 166) |

Записи 2026-10-29 зібрано з журналу живої гри; `expect` — ціни, які видає нинішній розбір, звірені з журналом
(розбіжності пояснено: 423 у «Роздертої шкури койота» — ціна сусідньої картки, 5546 і 51050 — «$», прочитаний як «5»).
Очима з грою не звірено.

## Як записати

1. Запустити програму з трасуванням: `set QHUB_PRICE_TRACE=1 && npm.cmd start` (у теці `desktop`).
2. Підійти до скупника, відкрити вікно й прокрутити список так, як потрібно для запису.
3. У журналі `vision.log` (тека даних програми) рядки `trace [...]` — по одному на кадр; кадр належить скупнику з
   наступного рядка `cover <скупник>: …`. Скопіювати їх у `frames`, межі товарів — у `items`.
4. Перевірити файл: у тексті немає ніків, чату й нічого, крім вікна скупника (решту — на `~`). Записати `expect`.
