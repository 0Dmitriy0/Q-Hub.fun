# Quickstart: перевірка написів мапи

## Передумови

- Застосовано `supabase/migrations/0070_map_labels.sql` (вручну, SQL власнику через буфер). Таблиця порожня.

## 1. Тести

```
npx.cmd vitest run src/lib/mapLabel.test.ts
```
Межі повернутого напису, розбиття смужок по частинах мапи.

SQL: `supabase/tests/map_labels_test.sql` — anon/user/editor не пишуть; admin пише; межі полів відхиляються.

## 2. Сайт

```
npx.cmd vite --mode production
```
- Мапа → шар «Назви місць»: порожньо — старих назв немає ніде.
- Адміном: «Новий напис» → «ФЕРМА», шрифт Oswald, жовтий, чорна обводка, кут 30°, розмір 60 м → видно наживо → зберегти → гість бачить.
- Потягнути кутову ручку — поворот і розмір; центр — перенести; видалити з підтвердженням.
- Вимкнути інтернет на сторінці (DevTools offline) і перезавантажити шрифт — напис запасним шрифтом, не зникає.

## 3. Мапа для гри

- «Мапа для гри» з «Назвами»: перегляд показує ті самі написи; змінити розмір значків 5 → 20 м — написи не змінюються (SC-004).
- Завантажити архів, поставити в гру: написи на великій мапі (пауза) і на радарі; у ньому немає `names.zip`-файлів старого шару.

## 4. Програма

```
npm.cmd run build:app
cd desktop && npm.cmd start
```
(закрити Q-Hub власника) — Alt+M: ті самі написи; без інтернету — з копії мапи. Пункт у `changelog.json` (верхній pending).
