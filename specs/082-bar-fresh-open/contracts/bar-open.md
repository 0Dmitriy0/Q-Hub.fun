# Contract: що видно при відкритті Alt+Q

| Перед відкриттям | Що бачить гравець |
|---|---|
| Пошуки/питання в попередніх відкриттях | Згорнута плашка, порожній рядок; старе — в «Історії» |
| Відповідь ШІ прийшла, поки плашку сховали | Лише ця відповідь |
| ШІ ще думає | Згорнута / «ШІ думає…», відповідь з'явиться, коли прийде |
| Режим цін | Згорнута, порожній рядок, без списку |

Режим (правила/ШІ чи ціни) — останній вибраний. «Історія», Alt+S, Alt+F9, налаштування — без змін.
