# Quickstart: Alt+Q щоразу чиста

## Тести (агент)

```bash
npx.cmd vitest run src/desktop/barReset.test.ts
npx.cmd tsc --noEmit -p .
```

## У програмі (власник)

| # | Дії | Очікування |
|---|---|---|
| 1 | Alt+Q → «зелена зона» Enter → Esc → Alt+Q | Згорнута плашка, порожній рядок |
| 2 | Кнопка «Історія» | «зелена зона» є, відкривається без нового запиту |
| 3 | Два пошуки поспіль в одному відкритті | Обидві відповіді видно (як зараз) |
| 4 | Shift+Enter (ШІ) → одразу Esc → зачекати 10 с → Alt+Q | Видно лише цю відповідь ШІ |
| 5 | Режим цін → «шкура» → Esc → Alt+Q | Згорнута, режим цін лишився |
