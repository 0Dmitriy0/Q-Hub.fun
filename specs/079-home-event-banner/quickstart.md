# Quickstart: перевірка першого екрана головної

## Тести (агент)

```bash
npx.cmd vitest run src/lib/halloween.test.ts   # рішення «показати картку» (research R4)
npx.cmd tsc --noEmit -p .
```

## У браузері

Дев-сервер з базою: `npx.cmd vite --mode production` (пам'ять `dev-server-needs-production-mode`), відкрити `/`.

| # | Стан | Дії | Очікування |
|---|---|---|---|
| 1 | Івенту немає (зараз: Хелловін скінчився) | Відкрити `/` у новій вкладці; DevTools → Application → Local Storage — ключа `qhub-hero-event` немає | Картка не з'являється ні на кадр; текст на всю ширину (SC-001, SC-002) |
| 2 | Те саме | DevTools → Network → «Slow 3G», оновити | Те саме, і після приходу даних нічого не змінюється |
| 3 | Те саме | Вручну додати `qhub-hero-event = ghosts`, оновити | Картка видна, після даних зникає один раз; ключ видалено; наступне оновлення — без картки |
| 4 | Ширина < 1000 px | Звузити вікно | Одна колонка; без івенту картки немає |
| 5 | Івент є (на тестових даних: тимчасово прибрати дату кінця івенту HALLOWEEN в адмінці або перевірити вже після наступного івенту) | Відкрити `/` вперше | Картка з'являється праворуч один раз (SC-004); ключ записано |
| 6 | Івент є | Оновити | Картка з першого кадру, текст не стрибає (SC-003) |

Скріншоти: 1440 px і 390 px, стан без івенту.
