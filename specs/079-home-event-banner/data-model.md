# Data Model: Банер івенту на головній

База не змінюється.

## Стан івенту (з бази, як зараз)

- `ghosts` — кількість міток категорії `pryvydy`; `pumpkins` — `harbuzy`.
- `ended` — у сезонного івенту з назвою «halloween» є дата кінця, і вона минула (за Києвом).
- **Івент є** ⇔ `!ended && (ghosts > 0 || pumpkins > 0)` (FR-006, без змін).

## Підказка на пристрої

- **Ключ**: `localStorage['qhub-hero-event']`.
- **Значення**: `ghosts` | `pumpkins` | `both`; відсутній — «івенту не було / ще не знаємо».
- **Запис**: коли дані прийшли й івент є — тип картки; коли дані прийшли й івенту немає — ключ видалити. Без бази (помилка запиту) — не чіпати.
- **Помилки сховища** (приватний режим): ігнорувати, поводитися як без підказки.

## Переходи першого екрана за візит

| Підказка | Дані бази | Що бачить гравець |
|---|---|---|
| немає | ще не прийшли | текст на всю ширину |
| немає | івенту немає / помилка | без змін — текст на всю ширину (SC-001) |
| немає | івент є | картка з'являється праворуч один раз (SC-004) |
| є | ще не прийшли | картка з першого кадру, текст ліворуч (SC-003) |
| є | івент є | без змін (текст картки уточнюється, розкладка та сама) |
| є | івенту немає | картка зникає один раз, підказку видалено (edge case) |
