# Quickstart: перевірка етапу 1

```
npm.cmd test                      # корінь: логіка (src/lib/alerts.test.ts) та інтерфейс
cd desktop && npm.cmd test        # головний процес
cd desktop && npm.cmd start       # програма
```

1. Налаштування → «Сповіщення» → «Перевірити сповіщення»: спливає сповіщення Windows.
2. **075**: Alt+Q → Tab («Ціни») → скупник → дзвіночок біля товару з повзунком у зеленій зоні й свіжою ціною. До 5 хв — «Час здавати: …». Далі тиша, поки ціна та сама.
3. **076**: «Сповіщення» → увімкнути «Нагадувати про івенти», вибрати «Лотерея» → о :50 — «Лотерея — через 10 хв».
4. **077**: над плашкою «Таймер оголошення» → `2` → Enter → «Оголошення · ще 2 год». Вийти з програми, запустити — залишок менший на час простою. Щоб не чекати: у `%APPDATA%\Q-Hub\settings.json` зменшити `market.<id>.ends` (програма закрита).
