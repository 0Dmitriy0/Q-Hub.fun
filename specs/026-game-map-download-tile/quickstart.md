# Quickstart: «Мапа для гри»

## Автоматично

```sh
npx.cmd vitest run src/lib/gamePreview.test.ts
npx.cmd tsc --noEmit
```

## Вручну

`npx.cmd vite --mode production` → `/mapa?game=1`:

1. ≥ 1280×720: перегляд, вибір і «Скачати» видно разом; прокручується лише список (FR-005).
2. Зняти «Гарбузи» — зникли з перегляду одразу; тема й розмір значка міняють перегляд (FR-001–003).
3. Колесо / подвійний клік — наближення до міста, видно окремі значки; кнопка «Уся мапа» повертає (FR-004).
4. Група: згорнути, «усі» / «жодної» — змінюється лише вона (FR-007).
5. Велика категорія при 20 м — плашка з кнопками «7 м» / «12 м»; світла тема — плашка під перемикачем (FR-008).
6. «Жодної» — кнопка «Вибери хоча б щось», поруч «Скачати лише мапу».
7. Телефон (390 px): перегляд зверху, «Скачати» прилипає донизу.
8. SC-004: архів за однакового вибору — той самий склад файлів, що до переробки.
9. Головна → «Мапа для Quant RP»: мініатюра міняється з темою; «Зібрати мапу для гри» відкриває вікно в цій темі.
10. SC-002: 5 наборів — перевірка в грі (власник).
