# Quickstart: перевірка чернеток міток

Контракти — [contracts/](./contracts/), схема — [data-model.md](./data-model.md).

## Передумови

- Міграція `0019_map_drafts.sql` застосована (Supabase → SQL Editor або CI).
- Три акаунти: `admin`, `editor`, `user`.
- Програма зібрана: `cd desktop && npm.cmd start`.
- Набір знімків великої карти для тестів у `desktop/src/fixtures/map/` (20+ шт., біля відомих міток, масштаби 100–1000 м; щонайменше один — з нестандартною палітрою).

## 1. Автоматичні тести

```powershell
npm.cmd test                       # сайт: vitest (пошук дублів у радіусі 30 м)
cd desktop; npm.cmd test           # програма: mapmatch, outbox, клавіша
bash supabase/tests/run.sh         # RLS і RPC чернеток (у CI / WSL)
```

Очікування: усе зелене; `mapmatch` на наборі знімків — ≥ 90% у межах 30 м, ≤ 2% хибних > 100 м (SC-002, SC-003).

## 2. Точка з гри (історія 1)

1. Увійти в програму як `editor`. Стати біля мітки, яка вже є на мапі Q-Hub.
2. Відкрити велику карту, шкала ~500 м, натиснути **F9**.
3. Очікування: за ≤ 3 с «Точку збережено»; гра не втратила фокус.
4. На сайті як `admin` → Мапа → «Чернетки»: нова чернетка ≤ 30 м від мітки.

## 3. Відмови

| Дія | Очікування |
|-----|------------|
| F9 без відкритої карти | «Відкрийте велику карту…», чернетки немає |
| F9 на шкалі 2750 м | «Наблизьте карту», чернетки немає |
| F9 двічі за 2 с | одна чернетка |
| F9 під `user` | нічого; F9 доходить до гри |
| вимкнути мережу, F9, увімкнути | чернетка з'являється на сайті ≤ 30 с після появи мережі, без дублів |

## 4. Модерація (історії 2–3)

1. `admin` відкриває чернетку → мапа центрована на точці, знімок видно.
2. Без категорії «Опублікувати» → «Оберіть категорію».
3. Обрати категорію, підсунути точку → «Опублікувати на карті» → мітку видно в анонімному вікні.
4. Те саме в другій вкладці → «Чернетку вже оброблено».
5. Друга чернетка поруч → попередження «Поруч уже є: …».
6. `editor` бачить лише свої чернетки, без кнопок; `user` і гість — нічого (і в мережевих відповідях).

## 5. Знімки

- Посилання на знімок чужої чернетки під `editor` → помилка доступу.
- Опублікована мітка не містить знімка.
- Чернетку, оброблену > 30 днів тому (змінити `reviewed_at` у тестовій базі): після відкриття панелі admin знімок видалено, `shot_deleted_at` заповнено.

## 6. Інша палітра

Встановити стандартні текстури карти GTA (або інший мод) → повторити крок 2. Очікування: точка ≤ 30 м або «точку не визначено», але не хибна точка.
