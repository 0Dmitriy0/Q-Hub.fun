# Data Model: Точніші координати мітки Alt+F9

Без змін у базі й на диску (крім нових перевірочних кадрів у `desktop/src/fixtures/map`).

## Результат `locate()` (`desktop/src/mapmatch.cjs`)

| Поле | Зміна |
|---|---|
| `kind` | без змін: `point` / `unsure` / `no_map` / `zoom_in` / `zoom_out` |
| `x`, `y` | точка — після етапу 3, якщо його прийнято |
| `match.score`, `match.ratio`, `match.agree` | без змін (етап 2) |
| `match.fine3` | **нове**: `{ r, k, score, agree, dx, dy }` — крок етапу 3 (м/пікс), підібрана поправка масштабу, бал, узгодженість, зсув від точки етапу 2 (м); `null`, якщо етап 3 не прийнято. Пишеться в `match` чернетки/пропозиції — для розбору спірних міток |

## Прев'ю (`src/desktop/pinPreview.ts`)

- Вхід: `x`, `y` (метри гри), `size` (пікс, за замовчуванням 240).
- Вихід: `{ tiles: { z, tx, ty, left, top }[], pin: { left, top } }` — плитки рівня 6 (256 пікс), що покривають квадрат `size` з точкою в центрі; координати плиток відносно квадрата; плитки поза мапою (`tx`/`ty` < 0 чи ≥ 64) не включаються.
