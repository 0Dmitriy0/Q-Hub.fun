# Implementation Plan: Інструкція «Як поставити мапу в гру» — зручна для читання, посилання плитками

**Branch**: `027-map-guide-redesign` | **Date**: 2026-10-31 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/027-map-guide-redesign/spec.md`

## Summary

Інструкція вже живе в `public.guides.install` як текст із простими рядками-позначками (`Знімок: …`, specs/023).
Розширюємо ту саму мову, без міграції: `Потрібно: назва | навіщо | посилання [| необов'язково]` — плитка,
`Етап: назва` — заголовок етапу, `Важливо: …` — попередження, `[Кнопка]` — кнопка програми, шлях з `\` —
блок із «Копіювати» (розпізнається сам), `https://…` — посилання. Розбір — чисті функції в `src/lib/guide.ts`,
сторінка `GameMapGuide.tsx` лише малює. Позначки «зроблено» — `localStorage` з версією кроків. Старий текст
читається як раніше (один список), тож сайт можна випустити до того, як адмін вставить новий текст.
