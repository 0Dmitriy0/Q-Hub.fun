# Data Model: інструкція «Як поставити мапу в гру»

Схема бази не змінюється: `public.guides` (0035), поле `install`.

## Мова тексту `install` (розбирає `src/lib/guide.ts`)

| Рядок / блок | Значення |
|---|---|
| `Потрібно: Назва \| навіщо \| посилання [\| необов'язково]` | плитка «Що потрібно»; посилання `https://…` (зовнішнє) або `/…` (сторінка сайту); зламана плитка не показується |
| `Етап: Назва` (перший рядок блоку) | заголовок етапу; кроки після нього — в етапі |
| порожній рядок | межа кроків |
| `Важливо: …` (початок кроку) | попередження |
| `Знімок: https://…` | картинка до кроку (як у specs/023) |
| слово з `\` | шлях із «Копіювати» |
| `[Текст]` | кнопка програми |
| `https://…` | посилання в новій вкладці |

## Обчислювані сутності

- **GuideTile** `{ name, why, url, optional, external }`
- **GuideStage** `{ title, first, steps }` — `first` — наскрізний номер першого кроку; етап без назви — кроки до першого `Етап:`
- **GuideStep** `{ text, image, warn }`
- **Позначки гравця** — `localStorage['qhub-guide-done:' + version(install)]` = масив номерів кроків
