# Quickstart: перевірка інструкції

## Автоматично

```sh
npx.cmd vitest run src/lib/guide.test.ts
npx.cmd tsc --noEmit
```

## Перехід стартового тексту (FR-012, власник)

1. Після випуску сайту відкрити `/mapa/v-gru` під адміном → «Змінити інструкцію».
2. Поле «Що потрібно — плитки» і «Як поставити» — з [install-text.md](install-text.md); у «Не вийшло?» `«Редагувати»` → `[Редагувати]`.
3. Зберегти. До цього кроку сторінка показує старий текст одним списком — нічого не ламається.

## Сторінка (SC-001, SC-003–SC-006)

`npx.cmd vite --mode production` → `/mapa/v-gru`:

1. 4 плитки: OpenIV, ArchiveFix, mapzoomdata.meta — нова вкладка на правильну адресу; «Карта для гри» — мапа з вікном «Мапа для гри»; mapzoomdata — пунктирна з «необов'язково».
2. Зміст праворуч (ПК) / «Етапи інструкції» (телефон): клік — етап розгортається й прокручується.
3. Етап згортається кліком чи Enter на заголовку.
4. «Позначити зробленим» → перезавантаження → позначка лишилась; «Почати знову» скидає.
5. «Копіювати» біля `GTAV\update\update.rpf\x64\levels\gta5` → «Скопійовано», вставка збігається символ у символ.
6. Резервна копія — жовта плашка «Важливо».
7. Світла й темна тема; ширина 375 px — без горизонтальної прокрутки.
