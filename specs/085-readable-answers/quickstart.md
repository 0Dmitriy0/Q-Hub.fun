# Quickstart: перевірка читабельного тексту

## Передумови

- Гілка з реалізацією; `npm.cmd ci` у корені й у `desktop/`.
- Для перевірки промпту — задеплоєна функція `assistant` (`supabase functions deploy assistant --yes`).

## 1. Модульні тести

```
npx.cmd vitest run src/desktop/richText.test.ts src/desktop/barParts.test.ts supabase/functions/assistant/plan.test.ts
```

Очікується: зелені; кейси з data-model.md (абзаци, списки, жирне, зламані `**`, `#`, порожні рядки, порожній вхід) і `plainText` без `**`.

## 2. Плашка в програмі

Закрити запущену Q-Hub власника, зібрати й запустити: `cd desktop && npm.cmd start`.

1. Alt+Q → Shift+Enter «що буде за угон авто» → відповідь: перше речення — головна думка, далі список; суми/строки жирні; позначки пунктів помаранчеві; зірочок немає (US1, SC-001–003).
2. «Копіювати» → вставити в Блокнот → без зірочок, пункти з «• », абзаци з нових рядків (FR-006).
3. Enter «каф» → у картках номер і покарання помітні за ≤ 2 с; довгий пункт згорнутий зі згасанням, «Показати повністю» розгортає (US2).
4. Відповідь ШІ → «Окремо» → закрити Alt+Q → у вікні ті самі абзаци й списки (US3).
5. «Історія» → стара відповідь (до зміни) показується без втрат (FR-012).

## 3. Контраст

Перевірити `--fg`, `--muted`, `--faint`, `.bpen` на фоні карток (`#18212d`) і вікна (`rgba(14,18,24,.96)`): ≥ 4,5 : 1 основний, ≥ 3 : 1 другорядний (SC-004).

## 4. Демо на сайті

`npx.cmd vite --mode production` → демо плашки на головній: картки правил у новому вигляді, без горизонтальної прокрутки на 375px.
