# Quickstart: перевірка 043 «Довідник від гравців»

## Підготовка

1. Застосувати `supabase/migrations/0057_community_wiki.sql` у Supabase → SQL Editor (SQL — у буфер з файлу, не з чату; пам'ять discord-bot-ops).
2. Перевірити, що міграція справді на базі (пам'ять prod-migrations-gaps):
   `select count(*) from public.jobs;` — стільки ж, скільки робіт у `src/data/jobs.ts`;
   (`wiki_versions` спершу порожня: початкова версія картки записується сама при першій прийнятій правці);
   `select policyname from pg_policies where tablename = 'vehicles';` — запис лише admin.
3. Тести бази: `bash supabase/tests/run.sh` (новий `wiki_test.sql`); сайт: `npx.cmd vitest run`, `npx.cmd tsc --noEmit -p .`.
4. Локально з робочою базою: `npx.cmd vite --mode production` (пам'ять dev-server-needs-production-mode).

Потрібні три акаунти: гравець (`user`), модератор (`moderator`), адмін.

## Сценарії

1. **Роботи з бази (FR-026).** `/wiki/roboty` показує ті самі роботи, що до міграції; мапа → мітки робіт з назвами й рівнями. Без бази (`npm run dev`) — роботи з `src/data/jobs.ts`.
2. **Правка (US1).** Гравцем: «Акванавт» → «Запропонувати правку» → змінити «Оплата», джерело «гра» → надіслати. Картка не змінилась; кабінет → «Мої правки» — «на розгляді».
3. **Гість (FR-007).** Без входу «Запропонувати правку» → вхід Discord → та сама картка з відкритою формою.
4. **Черга (US3 AC1, FR-010).** Модератором: адмінка → «Довідник» — пропозиція з «було → стало», автором, джерелом. Прийняти → картка оновилась, «Оновлено <дата>», автор правки — на картці.
5. **Відхилення (FR-011).** Друга пропозиція → «Відхилити» без причини — не дає; з причиною «копія з іншого сайту» → у гравця «відхилено» з причиною і значок у кабінеті (FR-018).
6. **Конфлікт (US1 AC7).** Дві пропозиції до однієї картки; прийняти першу → друга «конфлікт», зміни показано поверх нової версії, «Прийняти поверх нової версії» працює.
7. **Відкат (US3 AC3, SC-005).** Історія картки → повернути версію 1 → картка як до правок, в історії — запис «відкат».
8. **Нова сторінка (US2).** «Додати роботу» з назвою «акванавт» → підказка «Можливо, це вже є: Акванавт». Нова назва → прийняти → є у списку й за адресою.
9. **Транспорт.** Пропозиція до авто змінює лише характеристики; поля картинки й моделі у формі немає; `editor` більше не зберігає авто напряму (лише пропозиція).
10. **Ліміт і заборона (FR-013, FR-014).** 11-та пропозиція на розгляді — зрозумілий текст; заблокований гравець бачить причину замість форми.
11. **Скрін-доказ (FR-024, SC-006).** Скрін видно автору й модератору; іншому гравцю за прямою адресою — відмова; після рішення файл зник зі сховища.
12. **Права (SC-004).** Гравцем через REST: `update jobs …` і `rpc/wiki_decide` → відмова (перевіряє `wiki_test.sql`).
13. **Рейтинг (US4).** Після трьох прийнятих правок гравець — у рейтингу «Довідник», адмінка → «Гравці» показує прийняті/відхилені й дає змінити роль.
