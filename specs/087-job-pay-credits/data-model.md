# Data Model: Хто й коли заміряв заробіток роботи

Нових таблиць і полів немає — лише читання.

## Вхід: версія роботи (з `public.wiki_versions`)

| Поле | Тип | Примітка |
|---|---|---|
| `version_no` | number | зростає з кожною версією |
| `kind` | `'seed' \| 'accept' \| 'revert' \| 'hide' \| 'unhide' \| 'admin'` | |
| `author` | uuid \| null | хто запропонував (для `accept`) |
| `decided_by` | uuid \| null | хто опублікував |
| `created_at` | ISO-рядок | дата публікації |
| `pay` | string | `data.pay` знімка роботи |

## Вихід: частина заробітку (`PayPart`)

| Поле | Тип | Правила |
|---|---|---|
| `text` | string | частина теперішнього `pay` (без крайніх пробілів) |
| `key` | string | до першої «:» у перших 40 знаках (нижній регістр, trim), інакше весь текст |
| `kind` | `'seed' \| 'proposal' \| 'admin' \| 'unknown'` | звідки частина |
| `by` | uuid \| null | автор пропозиції (`proposal`) чи той, хто додав (`admin`) |
| `approvedBy` | uuid \| null | модератор, якщо ≠ `by` (лише `proposal`) |
| `at` | ISO-рядок \| null | дата публікації версії-кредиту; `seed` — дата завантаження (лише для «давно»); немає історії — null |
| `stale` | boolean | `at` відома й старша за 30 днів від `now`; `at` null — `false` |

## Правила (contracts/pay-credits.md)

- Роздільник частин — ` · ` чи новий рядок; порожні частини відкидаються.
- Версії обробляються за зростанням `version_no`; `hide`/`unhide` пропускаються.
- Частина отримує кредит версії, де її текст (за ключем) став теперішнім; текст, що повернувся до вже баченого для цього ключа, бере кредит першої появи.
- `pay` останньої версії ≠ теперішній `job.pay` → результат порожній (підписів не показуємо).
- Порожній `pay` → порожній результат.
