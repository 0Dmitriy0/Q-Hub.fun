# Quickstart: перевірка підписів заробітку

## 1. Модульні тести

```
npx.cmd vitest run src/lib/payCredits.test.ts
```

Очікується: розбиття й ключі; кредит частини не змінюється від правок інших частин; заміна частини — новий кредит; відкат — кредит першої появи; `seed` → «з початкових даних»; `admin` → «додав»; модератор = автор → без «підтвердив»; > 30 днів → `stale`; розбіжність з `job.pay` → порожньо.

## 2. Сайт

`npx.cmd vite --mode production` → Довідник → Роботи → «Фермер» (чи робота з заробітком по частинах).

1. Під кожною частиною — «Заміряв … · дата · підтвердив …» (US1).
2. Робота з заробітком одним рядком із початкових даних — «З початкових даних довідника» (US3).
3. Частина старша за 30 днів — позначка «давно не перевіряли» (US2).
4. Відкрити «Історію змін» роботи — автори й дати збігаються з підписами (SC-002).
5. На 375 px — без горизонтальної прокрутки.
