# Tasks: Ліміти пам'яті й процесора для програми

**Input**: Design documents from `/specs/090-app-resource-limits/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/usage-log.md, quickstart.md

**Tests**: включено — конституція (принцип VI) вимагає модульних тестів `node --test` для чистої логіки. Для частин, що залежать від Electron і гри, перевірка — еталонний сценарій із quickstart.md.

**Organization**: задачі згруповано за історіями зі spec.md. Позначки H1–H6 і M1–M5 — гіпотези з research.md.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: можна робити паралельно (інший файл, немає залежності від незавершеного)
- **[Story]**: історія зі spec.md (US1–US4)
- **👤**: потрібен власник у грі — без нього задачу не виконати
- **(умовна)**: робиться лише якщо замір T010 підтвердив вагу гіпотези; інакше закривається записом «не підтверджено» в `measurements.md`

## Path Conventions

Програма — `desktop/src/` (CommonJS), скрипти — `desktop/scripts/`, інтерфейс вікон — `src/desktop/`. npm на Windows — `npm.cmd`.
