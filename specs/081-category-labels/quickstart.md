# Quickstart: галочка «назви міток» для категорії

## Перед злиттям (власник)

1. Supabase → SQL Editor → вміст `supabase/migrations/0067_category_labels.sql` (агент кладе в буфер) → Run.
2. Одразу після: адмінка мапи → «Змінити категорію» → для кожної категорії, де назви потрібні (магазини, заправки, банди…), поставити галочку → «Зберегти». **Без цього назви зникнуть скрізь** (рішення A).
3. Назви робіт і скупників (вбудовані категорії) — вимкнено в коді; щоб увімкнути — сказати агенту (правка `BUILTIN` у `src/lib/mapMarks.ts`).

## Тести (агент)

```bash
npx.cmd vitest run src/lib/mapData.test.ts
npx.cmd tsc --noEmit -p .
# SQL-тест — supabase/tests/run.sh (локальна база) або перевірка власником у SQL Editor
```

## Перевірка в браузері

| # | Дії | Очікування |
|---|---|---|
| 1 | Мапа, наблизити до z ≥ 5 | Під мітками категорій без галочки — назв немає; по кліку назва в картці є |
| 2 | Адмінка: категорії поставити галочку → Зберегти | Під її мітками з'явились назви; інші — без змін |
| 3 | Мітка з власним вимкненим підписом у категорії з галочкою | Під нею назви немає |
| 4 | «Нова категорія» | Галочка знята |
| 5 | Пошук на мапі за назвою мітки з категорії без галочки | Знаходить |
| 6 | Мапа в програмі (Alt+M) | Те саме, що на сайті |
