# Contract: підписи міток і галочка категорії

## База

- `map_categories.show_labels` — читає будь-хто (політика `read all`), пише лише admin.
- Міграція: `supabase/migrations/0067_category_labels.sql`; застосувати в Supabase → SQL Editor **до** злиття (інакше адмінка підкаже, а мапа покаже назви як зараз).

## Мапа (`MapPage`, сайт і програма)

- Підпис під міткою (тултіп `mlabel`, з наближення `LABEL_ZOOM`) — лише за правилом з data-model.md.
- Картка мітки по кліку й пошук — показують назву завжди.

## Адмінка мапи (лише admin)

- «Змінити категорію»: чекбокс «Показувати назви міток на мапі», значення з категорії; «Зберегти» записує `show_labels`.
- «Нова категорія»: той самий чекбокс, знятий за замовчуванням.
