# Implementation Plan: Мапа Q-Hub у програмі поверх гри

**Branch**: `014-desktop-map` (робота — у власній гілці, у `main` — після зелених тестів) | **Date**: 2026-10-29 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/014-desktop-map/spec.md`

## Summary

Плашка Alt+Q уже рендерить сайтовий React-код з диска (`vite.app.config.ts` → `desktop/src/ui`). Тому мапа в програмі —
це **та сама сторінка `MapPage` сайту** у новому вікні `map.html`, у режимі «лише перегляд» (`embed`): без адмінських
інструментів, «Карти для гри», «Скріну» й чернеток, зате з кнопкою «Де я?» і списком найближчих міток. Мітки, зони,
категорії, пошук, фільтри, іконки й кольори — спільний код із сайтом, тож вони не розійдуться (FR-003, SC-003).

Що додається:

1. **Вікно мапи** (`main.cjs`) — як «Історія»: без рамки, поверх гри, не на панелі завдань; місце — під плашкою Alt+Q,
   праворуч від «Історії» (≈80 % екрана). Створюється при першому відкритті, далі лише ховається (SC-002, FR-016).
   Клавіша Alt+M (змінюється в Налаштуваннях → Клавіші), кнопка «Мапа» в рядку плашки поряд з історією, Esc закриває.
2. **Дані мапи без CORS** — сайт не віддає заголовків CORS, тож з `file://` вікно не завантажить шматки мапи й назви.
   Програма реєструє свій протокол `qmap://`, який бере файли `/map/…` з сайту й кешує на диску (`%APPDATA%\Q-Hub\map`);
   без інтернету — з кешу (FR-013). `mapUrl()` у вікні програми веде на `qmap://`.
3. **Мітки свіжі й офлайн** — `loadMapData()` при кожному відкритті, якщо минуло ≥ 5 хв (FR-012); остання вдала копія — у
   `localStorage` вікна з датою, без інтернету — вона й напис «станом на …» (FR-013).
4. **«Де я?»** — наявний локатор F9 (`mapmatch.worker.cjs` + OCR шкали) стає доступним усім (FR-009). Клавіша мапи при
   відкритій великій карті гри: знімок → показ мапи → позначка «Ти тут», коли локатор відповість (FR-008a). Кнопка «Де я?»
   у відкритій мапі на мить ховає вікна програми й знімає екран. Знімок — лише в пам'яті, нікуди не йде (FR-010).
5. **Найближчі мітки** від «Ти тут» — чиста функція `nearest()` з тестами (FR-011).
6. **Місця в рядку Alt+Q** — пошук плашки знаходить мітки мапи; клік відкриває мапу з міткою в центрі (FR-007).
7. **Версія 0.4.0** і запис у «Журналі оновлень» (FR-017).

## Technical Context

**Language/Version**: TypeScript/React 19 — вікно мапи (спільний код сайту); JavaScript CommonJS (Electron 37) — головний процес програми

**Primary Dependencies**: наявні — Leaflet 1.9, leaflet.markercluster, Supabase JS, tesseract.js 6 (OCR шкали), worker_threads (`mapmatch`); нових немає

**Storage**: Supabase (лише читання: `map_categories`, `map_points`, `map_areas`, `map_owners` — anon-доступ, як на сайті);
диск ПК: кеш файлів мапи `%APPDATA%\Q-Hub\map\site\…`, `settings.json` (клавіша мапи, розмір); `localStorage` вікна мапи
(фільтри — ті самі ключі, що на сайті; кадр; копія міток з датою)

**Testing**: `vitest` — `nearest()`, режим `embed` (що ховається), пошук місць у плашці, `mapUrl` з базою; `node --test` —
кеш протоколу `qmap` (шлях, Last-Modified, офлайн), розміщення вікна мапи (чиста функція від меж екрана, плашки й історії)

**Target Platform**: Windows 10/11, гра GTA V (RAGE MP) у режимі «вікно без рамки»

**Project Type**: desktop-app (Electron) + спільний веб-код (Vite/React)

**Performance Goals**: відкриття мапи ≤ 1 с після першого відкриття за сеанс (SC-002); з відкритою мапою FPS гри −≤10 % (SC-005)

**Constraints**: лише перегляд (FR-014, принципи II/V); знімок — лише на дію гравця і лише в пам'яті (FR-010, принцип III);
жодної взаємодії з грою, крім знімка (FR-015, принцип I); мапа в програмі — лише темна (specs/019)

**Scale/Scope**: ~2 800 міток, 39+ категорій, ~10 зон; тайли z0–6 ~5,4 МБ, шматки z7+ ~2,3 МБ, назви ~1,2 МБ + `names.bin`

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

| Принцип | Як дотримано | Стан |
|---|---|---|
| I. Зовнішній інструмент | Мапа лише показує; дані з гри — тільки знімок екрана на дію гравця («Де я?», клавіша мапи). Ні натискань у грі, ні маршрутів у гру | ✅ |
| II. Права — у базі | Мапа читає ті самі таблиці під anon/гравцем, що й сайт; режим `embed` ховає адмінські інструменти, але права й так у RLS. Програма нічого не пише в мапу | ✅ |
| III. Знімки приватні | Знімок для «Де я?» живе лише в пам'яті головного процесу, не зберігається й не надсилається (на відміну від F9, де чернетка з дозволу йде адміну) | ✅ |
| IV. Перевірені дані | «Де я?» при невпевненості локатора — без позначки, з підказкою; ті самі пороги, що F9 | ✅ |
| V. Програма лише додає, офлайн | Мапа нічого не змінює; без інтернету — кеш файлів і остання копія міток з датою | ✅ |
| VI. Тести | Нових правил бази немає; чиста логіка (`nearest`, розміщення вікна, кеш `qmap`, пошук місць) — модульні тести | ✅ |

**Post-design re-check (після Phase 1)**: без змін — ✅. Відхилень немає, Complexity Tracking порожній.

### Source Code (repository root)

```text
map.html                         # нова точка входу Vite (поряд з bar.html, history.html)
vite.app.config.ts               # + input map
src/
├── pages/MapPage.tsx            # + проп embed: ховає адмінку, «Карту для гри», «Скрін», чернетки; + слот «Де я?»
├── lib/mapGeo.ts                # mapUrl(): база qmap:// у вікні з file://
├── lib/mapNear.ts (+ .test.ts)  # nearest(): найближчі мітки категорії від точки, з відстанню
└── desktop/
    ├── mapMain.tsx              # вікно мапи: MemoryRouter + AuthProvider + <MapPage embed />, тема темна
    ├── MapWhere.tsx             # «Де я?», «Ти тут», найближчі
    ├── mapCache.ts (+ .test.ts) # копія міток з датою в localStorage; «станом на …»
    ├── barSearch.ts (+ test)    # + пошук місць (міток мапи) для рядка Alt+Q
    ├── Bar.tsx                  # кнопка «Мапа», результати-місця
    └── Settings.tsx             # клавіша мапи (з перевіркою конфлікту)
desktop/
├── package.json                 # version 0.4.0
└── src/
    ├── main.cjs                 # вікно мапи, клавіша, IPC, «Де я?» (локатор для всіх), протокол qmap
    ├── mapwin.cjs (+ .test.cjs) # розміщення вікна мапи (чиста функція)
    ├── qmap.cjs (+ .test.cjs)   # протокол qmap:// з дисковим кешем
    └── preload.cjs              # + виклики мапи
src/data/changelog.json          # запис 0.4.0
```

**Structure Decision**: спільний код сайту (React) для вигляду й даних мапи + головний процес Electron для вікна, клавіші,
знімка й файлового кешу — та сама схема, що в плашки Alt+Q та «Історії».
