# Quickstart: перевірка мапи в програмі

## Підготовка

```powershell
npm.cmd run build:app          # інтерфейс програми (bar, history, map) у desktop/src/ui
cd desktop; npm.cmd start      # програма
```

Тести: `npx.cmd vitest run` (сайт і вікна програми), `cd desktop; npm.cmd test` (головний процес).

## Сценарії

| # | Дія | Очікування | Вимоги |
|---|---|---|---|
| 1 | Гра у вікні без рамки, Alt+M | Мапа поверх гри під плашкою, гра не згорнута, на панелі завдань нічого нового | FR-001, FR-001a |
| 2 | Esc / Alt+M ще раз | Мапа зникла, керування в грі без кліку | FR-002, FR-004 |
| 3 | Alt+Q → кнопка «Мапа» | Мапа праворуч від «Історії» (якщо відкрита), не перекриває плашку; клік у гру — ховаються обидві | FR-001 |
| 4 | Порівняти категорії з `/mapa` на сайті (гість) | Ті самі групи, кількість міток у кожній, іконки, кольори, картка мітки | FR-003, SC-003 |
| 5 | Пошук «24/7»; вимкнути всі групи, крім полів | Лише відповідні мітки; закрити й відкрити — фільтри й кадр ті самі | FR-005, FR-006 |
| 6 | У рядку Alt+Q «заправка» → результат-місце | Мапа з цією заправкою в центрі, картка відкрита | FR-007 |
| 7 | Велика карта гри (50–1500 м), Alt+M | Мапа з позначкою «Ти тут» ≤ 100 м від справжнього місця | FR-008, FR-008a |
| 8 | Без великої карти — «Де я?» | «Не видно шкали великої карти — відкрий її й спробуй ще», без позначки | FR-009 |
| 9 | «Ти тут» є → вибрати групу | «Найближчі» з відстанню | FR-011 |
| 10 | Додати мітку на сайті (admin), відкрити мапу через 5–10 хв | Нова мітка є | FR-012 |
| 11 | Вимкнути інтернет, перезапустити програму, Alt+M | Мапа (оглянуті місця) і мітки; напис «станом на …» | FR-013 |
| 12 | Програма під admin | Жодних кнопок правки, «Карти для гри», «Скріну», чернеток | FR-014 |
| 13 | Відкрита мапа — FPS гри (лічильник гри) | Падіння ≤ 10 %; закрита — без різниці | FR-016, SC-005 |
| 14 | 1366×768 | Мапа вміщається, панель фільтрів згортається | Edge cases |
| 15 | Налаштування → Клавіші: поставити мапі Alt+Q | «Клавіша вже зайнята» | FR-002 |

## Перевірка приватності «Де я?»

Після кількох «Де я?» у `%APPDATA%\Q-Hub` не з'являється нових знімків, у `pin.log` — лише рядки `where` з координатами
й причиною, без зображень (FR-010).
