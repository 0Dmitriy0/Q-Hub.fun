# Contract: виклики вікна мапи й плашки ↔ головний процес

Усі виклики — через `preload.cjs` (`window.qhub`), кожен перевіряє, з якого вікна прийшов (`fromMap(e)` / `fromBar(e)`).

## Вікно мапи → головний процес

| Виклик | Аргументи | Відповідь | Опис |
|---|---|---|---|
| `mapHide()` | — | — | Esc, хрестик: сховати мапу; якщо відкривали з плашки — фокус у плашку, інакше в гру (FR-004) |
| `mapWhere()` | — | `{ ok: true, x, y } \| { ok: false, why: string }` | «Де я?» кнопкою: сховати вікна → знімок → показати → локатор (FR-008a). `why` — текст з `WHY` |
| `mapKey()` | — | `string` | поточна клавіша мапи — для підказки в шапці |

## Плашка → головний процес

| Виклик | Аргументи | Відповідь | Опис |
|---|---|---|---|
| `mapToggle()` | — | `boolean` (відкрита) | кнопка «Мапа» в рядку плашки (FR-001) |
| `mapOpen(p)` | `{ id?: string, x: number, y: number }` | — | результат-місце з пошуку: показати мапу з цією точкою в центрі (FR-007) |

## Головний процес → вікно мапи (події)

| Подія | Дані | Коли |
|---|---|---|
| `map-shown` | `{ from: 'bar' \| 'key' }` | вікно показано: оновити мітки, якщо застаріли (FR-012) |
| `map-focus` | `{ id?: string, x, y }` | відкрито з результату пошуку |
| `map-where` | `{ state: 'busy' } \| { ok: true, x, y } \| { ok: false, why }` | клавіша мапи при відкритій великій карті: «шукаю…», потім результат |

## Налаштування

- `barPrefs({ mapKey })` — нова клавіша; відповідь `{ prefs, error? }`, `error` — «Клавіша вже зайнята: …» (конфлікт з
  `hotkey`, `pinKey`, `Alt+S` або інша програма тримає її).

## Гарантії

- Знімок для «Де я?» не виходить за межі головного процесу: у вікно йдуть лише `x, y` або причина (FR-010).
- Жоден виклик не пише в базу (FR-014).
