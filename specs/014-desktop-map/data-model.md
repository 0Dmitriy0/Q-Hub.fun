# Data Model: Мапа Q-Hub у програмі

Нових таблиць у базі немає. Мапа лише читає `map_categories`, `map_points`, `map_areas`, `map_owners` (як сайт).

## Копія мапи (localStorage вікна мапи, `qhub:map:copy`)

| Поле | Тип | Опис |
|---|---|---|
| at | ISO-рядок | коли завантажено з бази |
| cats | MapCategory[] | категорії (з вбудованими) |
| marks | MapMark[] | мітки |
| areas | MapArea[] \| null | зони |
| owners | Record<number, string> \| null | власники міток |

- Пишеться після кожного вдалого `loadMapData()`; читається, коли база недоступна (FR-013).
- Оновлення: показ вікна і `now − at ≥ 5 хв` (FR-012).

## Вибір гравця (localStorage вікна мапи)

- Фільтри — ті самі ключі, що на сайті: `qhub:map:on`, `qhub:map:open` (FR-006).
- Кадр — `qhub:map:view` = `{ x, y, z }` (на сайті кадр живе в адресі `#x,y,z`; у вікні адреси немає).

## Файли мапи (диск, `%APPDATA%\Q-Hub\map\site\`)

- Дзеркало `/map/…` сайту: тайли `{z}/{x}/{y}.webp`, `v/*.bin`, `n/…`, `game/names.bin`, `game/export.json`.
- `index.json` кешу: `{ "<шлях>": { v: MAP_V, lm: Last-Modified } }`. Інший `v` у запиті — перезавантажити файл.
- Ліміту розміру немає: вся мапа ~10 МБ.

## Позначка «Ти тут» (лише пам'ять вікна мапи)

| Поле | Тип | Опис |
|---|---|---|
| x, y | number | метри гри |
| at | number | час знімка |
| from | 'key' \| 'button' | звідки «Де я?» |

- Живе до закриття програми чи наступного «Де я?»; нікуди не надсилається.

## Налаштування програми (`settings.json → bar`)

| Поле | За замовчуванням | Опис |
|---|---|---|
| mapKey | `Alt+M` | клавіша мапи (FR-002) |

## Найближча мітка (обчислюється)

`{ mark: MapMark, cat: MapCategory, m: number }` — відстань у метрах, округлена до 10.
