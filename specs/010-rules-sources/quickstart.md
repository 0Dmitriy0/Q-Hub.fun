# Quickstart: перевірка правил і законів

## Один раз (власник)

1. Supabase → SQL Editor: `supabase/migrations/0037_rule_sources.sql`.
2. Функція: `supabase functions deploy rules-sync` і `supabase secrets set RULES_SYNC_SECRET=<випадковий рядок>`.
3. GitHub → Settings → Secrets: `RULES_SYNC_SECRET` (той самий), `SUPABASE_URL` уже є як `VITE_SUPABASE_URL` у `.env.production`.
4. Сайт → `/admin/pravyla` → «Оновити зараз» — перший знімок.

## Сценарії

| # | Дія | Очікування | Вимоги |
|---|---|---|---|
| 1 | Плашка: «штраф за швидкість» (Enter) | Серед перших 3 — стаття Дорожнього / Адміністративного кодексу з позначкою «Закон штату», документом, посиланням | FR-005, US1 |
| 2 | «скільки дають за викрадення авто» (Shift+Enter) | Відповідь зі «ст. 6.5 Кримінального кодексу» й посиланням | FR-006 |
| 3 | «вбивство в зеленій зоні» (Shift+Enter) | Окремо: правило сервера (кара від адміністрації) і закон штату (кара в грі) | US1-3 |

| 6 | Адмін: додати `https://example.com/…` | Відмова українською, джерело не збережене | FR-011 |
| 7 | Не-адмін: змінити `rule_sources` | База відхиляє | FR-012 |

Тести: `npx.cmd vitest run`, `cd desktop; npm.cmd test`, SQL — у CI (`supabase/tests/run.sh`).
