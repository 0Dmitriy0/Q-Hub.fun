# Contract: функція `rules-sync`

`POST <SUPABASE_URL>/functions/v1/rules-sync`

## Хто може викликати

- `Authorization: Bearer <сесія>` користувача з `profiles.role = 'admin'` — кнопка «Оновити зараз»;
- або заголовок `x-sync-secret: <RULES_SYNC_SECRET>` — щоденний запуск з GitHub Actions.
- Інакше — `403 { error: 'Оновлювати правила може лише адміністратор.' }`.

## Що робить

1. Читає `rule_sources` (service-ключ), попередній `rules/rules.json`.
2. Увімкнені розділи → їхні підрозділи й теми (крім тем, вимкнених окремим джерелом); окремі теми — як є. Кожна тема — один
   раз; запити до форуму послідовно.
3. Розбирає теми (`parse.ts`), тип — від джерела.
4. Джерело з помилкою чи 0 пунктів — його теми з попереднього знімка (FR-015).
5. Пише `rules/rules.json` (`upsert`, `cache-control: max-age=300`), у кожне джерело — `title, items, synced_at | error, diff`.

## Відповідь `200`

```json
{ "fetched": "2026-10-29T10:00:00.000Z", "topics": 53, "items": 4410,
  "sources": [{ "id": 2, "title": "Законодавча база Штату", "items": 2980, "error": null, "diff": { "added": 2980, "changed": 0, "removed": 0 } }] }
```

## Помилки

- `502` — не вдалося записати знімок (попередній лишається).
- Помилка окремого джерела — не помилка всієї відповіді: `sources[].error`.
