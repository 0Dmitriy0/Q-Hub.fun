# Quickstart: перевірка 030

## Автотести

```sh
npx.cmd vitest run src/lib/saleGuess.test.ts src/lib/txFilter.test.ts src/lib/txCsv.test.ts src/lib/perHourByCat.test.ts src/lib/advice.test.ts
cd desktop && npm.cmd test
```

Очікувано: усе зелене. `saleGuess` покриває один товар, кратні ціни (`manual`), «Продати все», нестачу (`farm`) і кг.

## У грі (власник, програма з цієї гілки)

1. **Один товар.** На складі 15 шкур оленя (через «Купив»). Продай скупнику 10. У плашці «Продав 10 × Шкура оленя по … $» → Enter. Склад: 5. Облік: один запис «Продаж фарму», нового немає.
2. **Без складу.** Продай товар, якого на складі немає → «Нафармив і продав N × …» → Enter. Склад не змінився, в «Угодах» дві угоди.
3. **Продати все.** Склад: два види шкур. «Продати все» у грі → «Продав усе: …» одним Enter.
4. **Скасувати.** Підтверди й одразу натисни «Скасувати» → угоди зникли, запис про гроші лишився.
5. **Видалення в кабінеті.** Видали угоду списання в «Угодах» → запис «Продаж фарму» в обліку лишився.
6. **Склад.** Товар з ціною < 40 % між мін і макс → «краще почекати». Товар, якого не купує жоден скупник, — у блоці «Не купує жоден скупник».
7. **Облік.** «Лише автоматичні» + «Сьогодні» → лише записи програми й їхня сума. «Вивантажити» → файл відкривається в Excel з кирилицею.
