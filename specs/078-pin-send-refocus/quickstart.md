# Quickstart: перевірка «назад у гру після мітки»

## Тести (агент)

```bash
cd desktop && npm.cmd test        # node --test: gamefocus.test.cjs з новими випадками (research R3)
```

Димова перевірка `main.cjs` — підробленим electron, не `npm start`, якщо Q-Hub власника запущена (пам'ять `main-smoke-fake-electron`).

## Перевірка в грі (власник)

Передумови: збірка з цієї гілки (артефакт `Q-Hub-Setup` з Actions або `cd desktop && npm.cmd start`), гра в режимі «вікно без рамки», вхід у Q-Hub.

| # | Дії | Очікування |
|---|---|---|
| 1 | Alt+F9 на карті гри → категорія + назва → **кнопка** «Надіслати мітку» → не чіпаючи миші, W | Форма зникла, персонаж іде; угорі кілька секунд «Мітку надіслано на розгляд…» (SC-001) |
| 2 | Те саме, але **Enter** | Те саме (SC-002) |
| 3 | Alt+F9 → **Esc** → W | Персонаж іде, «Не надіслано.» (SC-002) |
| 4 | Alt+F9 → «Не надсилати» → W | Те саме |
| 5 | Alt+F9 → без назви → «Надіслати мітку» | Форма лишилась, підказка «Напиши назву місця.», фокус у формі |
| 6 | Вимкнути інтернет → п. 1 | Персонаж іде одразу; «Відправлю, щойно буде інтернет» (SC-003) |
| 7 | Alt+F9 → клік у вікно Discord (форма лишилась видимою) → клік мишею по «Не надсилати» у формі | Форма зникла; фокус іде в гру лише якщо форма мала фокус у момент кліку — інакше програма Discord не перемикає (FR-006) |
| 8 | Перевірити «Кабінет» → «Мої правки» | Мітки з п. 1–2 є (SC-004) |

Кожен з п. 1–4 — 10 разів поспіль без промаху (SC-001/002).
