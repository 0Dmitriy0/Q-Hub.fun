# Contract: IPC `pin-decide` (плашка → головний процес)

Виклик: `window.qhub.pinDecide(send: boolean, hint?: { category?: string; note?: string; name?: string })` → `ipcRenderer.invoke('pin-decide', send, hint)`. Сигнатура не змінюється.

## Що головний процес обіцяє після виклику

1. Ігнорує виклик, якщо він не з плашки або немає форми, що чекає рішення (як зараз).
2. Ховає плашку.
3. **Нове**: якщо плашка мала фокус у момент виклику — повертає фокус запам'ятованому вікну гри (FR-001, FR-002, FR-006). Не чекає мережі (FR-004).
4. Виконує рішення як зараз: `send === true` — у чергу надсилання; інакше — «Не надіслано.».
5. Показує результат поверх гри без активації вікна; ховає сам через ~2,5 с, якщо плашку не закріплено (FR-003).

## Клавіша мітки (глобальна, за замовчуванням Alt+F9)

**Нове**: перед знімком запам'ятовує вікно на передньому плані як вікно гри (те саме, що клавіші плашки й мапи).
