# Data Model: Після «Надіслати мітку» — одразу назад у гру

Нових даних у базі чи на диску немає. Лише стан у пам'яті головного процесу програми.

## Вікно гри (запам'ятоване)

- **Що**: дескриптор вікна, яке було на передньому плані в момент клавіші плашки, мапи або (нове) клавіші мітки; наші вікна (плашка, мапа…) не запам'ятовуються.
- **Де**: `gameFocus()` у `desktop/src/gamefocus.cjs` (змінна всередині замикання).
- **Життя**: перезаписується кожним натисканням цих клавіш; якщо вікна вже немає (гру закрили) — повернення фокусу просто не відбувається.

## Форма мітки (очікує рішення)

- **Що**: `pinAsk` — знімок, точка, чернетка, що чекають «Надіслати» чи «Не надсилати».
- **Переходи**:
  - клавіша мітки → (запам'ятати гру) → знімок → форма показана з фокусом → `pinAsk` заповнено;
  - «Надіслати» / Enter / «Не надсилати» / Esc → форма закрита → фокус грі (якщо форма мала фокус) → надсилання в чергу / «Не надіслано» → результат поверх гри без фокусу;
  - не заповнено обов'язкове → форма лишається, фокус у формі (рішення в головний процес не йде).
