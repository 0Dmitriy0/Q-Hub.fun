# Contract: Івенти у WIKI — адреси й вигляд (055)

## Адреси

| Адреса | Що |
|---|---|
| `/wiki/iventy` | вкладка «Івенти»: банер, фільтр, плитки |
| `/wiki/iventy?f=now\|soon\|past` | фільтр (за замовчуванням — усе, крім архіву) |
| `/wiki/iventy/<slug>` | сторінка івенту |
| `/iventy` | → `/wiki/iventy` (зараз веде на `/`) |
| `/mapa?show=<cat1>,<cat2>` | велика мапа лише з категоріями івенту (наявний параметр) |

## Вкладка WIKI

Перемикач угорі: «Роботи · Транспорт · Івенти». Лічильник біля «Івенти» — скільки тривають зараз (без банера — 0 не
показується).

## Банер батл пасу (`kind = battlepass`, стан «Триває»)

Широка плашка над плитками: фото на всю ширину, «Батл пас», назва, дати («з 23.10 до 30.11»), «Ще N дн.», кнопка
«Нагороди й квести». Веде на сторінку. Немає батл пасу, що триває, — банера немає.

## Плитка

| Елемент | Джерело | Правило |
|---|---|---|
| фото 16:9 | `image_url` | порожньо — нейтральна заглушка з іконкою |
| позначка стану | `phase()` | «Триває» / «Скоро · через N дн.» / «Завершився»; ≤ 3 днів до кінця — «Ще N дн.» |
| назва | `title` | 1 рядок, обрізка |
| короткий опис | `description` | до 3 рядків, обрізка |
| дати | `range()` / «до оголошення» | рік — лише не поточний |
| мітка «Мапа · N» | кількість міток прив'язаних категорій | лише якщо є |

Порядок — `arrange()` (research R9). Фільтр «Тривають / Скоро / Архів» — сегментовані кнопки.

## Сторінка івенту

1. «← Усі івенти» → `/wiki/iventy`.
2. Фото, тип, назва, стан, дати.
3. Повний опис (`body`, формат R3); порожній — `description`.
4. Батл пас: таблиця «Рівень · Безкоштовно · Платно» (колонка «Платно» лише якщо є такі рядки).
5. Мапа (лише якщо є прив'язані категорії): «N локацій», міні-мапа, кнопка «Відкрити на великій мапі».
6. «Минулого разу» → сторінка `prev_id`, якщо є.
7. Неіснуючий slug — «Такого івенту немає» + «Усі івенти».

## Форма staff (на вкладці й на сторінці, кнопка «Додати івент» / «Змінити»)

Поля: назва, адреса (пропозиція `slugify(title)`), тип, дати (кінець — необов'язково), короткий опис, повний опис,
посилання, фото (`PicUpload`, кадр 640×360, `events/<id>.webp`), категорії мапи (вибір з папки «Івенти» з
кількістю міток), «попередній раз» (вибір з івентів), рівні батл пасу (рядки `рівень; нагорода; free|paid`).
Помилки — біля поля, без втрати введеного. Видалення — з підтвердженням з назвою івенту.
