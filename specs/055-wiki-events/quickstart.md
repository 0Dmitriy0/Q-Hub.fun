# Quickstart: перевірка «Івенти у WIKI» (055)

## Підготовка

1. Міграція: `supabase/migrations/0051_season_events_wiki.sql` у Supabase → SQL Editor (на робочій базі — вручну,
   див. пам'ять «Міграції на базі — вручну»).
2. Тести: `npx.cmd vitest run src/lib/eventsWiki.test.ts src/lib/seasons.test.ts`; SQL — `supabase/tests/run.sh` (у CI).
3. Сайт з базою: `npx.cmd vite --mode production` (не `npm run dev` — без бази).

## Сценарії

| # | Дія | Очікування | Spec |
|---|---|---|---|
| 1 | Відкрити `/wiki/iventy` | вкладка «Івенти» поруч з «Роботи» й «Транспорт», лічильник тих, що тривають | FR-001 |
| 2 | Є Хелловін (триває) і минулий івент | Хелловін першим з «Триває», минулий — лише у фільтрі «Архів» | US1, FR-003 |
| 3 | Осінній батл пас триває | широкий банер над плитками, серед плиток його немає | US3, FR-009 |
| 4 | Натиснути плитку Хелловіну | `/wiki/iventy/<slug>`: фото, дати, опис, мапа «N локацій» | US2 |
| 5 | «Відкрити на великій мапі» | `/mapa?show=harbuzy` — лише гарбузи; кількість = N зі сторінки | SC-001, SC-002 |
| 6 | Івент без категорій мапи | блоку мапи немає | US2 AC4 |
| 7 | `/wiki/iventy/nema-takoho` | «Такого івенту немає» + посилання | US2 AC6 |
| 8 | Головна → плитка в «Найближчі івенти» | веде на сторінку івенту | FR-006 |
| 9 | `editor`: додати івент з фото й категорією | плитка з фото з'являється | US4 |
| 10 | `user` / гість: запис у `season_events` в обхід інтерфейсу | відмова бази | SC-006 |
| 11 | Ширина 375 px | плитки в одну колонку, банер без горизонтального скролу | — |
| 12 | `/iventy` | → `/wiki/iventy` | — |
