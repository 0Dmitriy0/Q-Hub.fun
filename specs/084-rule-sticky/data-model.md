# Data Model: Окреме вікно з правилом (specs/084)

Бази не стосується. Усе — у головному процесі програми й у `settings.json`.

## RuleTab — вкладка (пам'ять головного процесу)

| Поле | Тип | Правило |
|---|---|---|
| `id` | string | `${topic}\|${n}\|${h}` — ключ без дубля |
| `topic` | string | назва документа, ≤ 300 |
| `url` | string | лише `https://forum.quant5.com.ua/…`, інакше `''` |
| `kind` | `'rules' \| 'law' \| 'order' \| 'info'` | інше → `'rules'` |
| `n` | string | номер пункту, ≤ 40, може бути порожнім |
| `h` | string | заголовок пункту, ≤ 300 |
| `s` | string | текст із покаранням, ≤ 8000 |
| `at` | number | час додавання — для «найстарішої» |

## RuleWinState — що бачить сторінка

| Поле | Тип | Опис |
|---|---|---|
| `tabs` | RuleTab[] | 0–5, у порядку додавання |
| `active` | string \| null | `id` активної вкладки |
| `locked` | boolean | `true` — Alt+Q закрита (зафіксовано) |
| `note` | string \| null | разова примітка («найстаріше закрито»), сторінка ховає за 4 с |

### Переходи (чисті функції `rulewin.cjs`, повертають новий стан)

- `addTab(state, hit, now)` → є такий `id` → лише `active = id`; є 5 → прибрати з найменшим `at`, `note`; додати, `active = id`.
- `activate(state, id)` → `active = id`, якщо така вкладка є.
- `closeTab(state, id)` → прибрати; закрили активну → активна сусідня праворуч, інакше ліворуч; `tabs` порожні → `active = null` (головний процес ховає вікно).
- `locked` міняє головний процес: показ / схов плашки (research R2).

## RuleWinBounds — збережене місце (`settings.ruleWin`)

| Поле | Тип | Правило |
|---|---|---|
| `x`, `y` | integer | екранні координати |
| `width` | integer | 280 … ½ ширини робочої області |
| `height` | integer | 160 … ½ висоти робочої області |

Перевірка під час відкриття — `place()` (research R4): перетин із робочою областю менший за 120×60 → типове місце. Видаляти поле не треба — неправильне просто ігнорується.
