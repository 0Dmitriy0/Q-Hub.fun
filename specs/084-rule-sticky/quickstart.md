# Quickstart: перевірка вікна з правилом (specs/084)

## Автотести

```bash
cd desktop && npm.cmd test          # rulewin.test.cjs серед інших
cd .. && npx.cmd vitest run src/desktop
npx.cmd tsc -b                      # типи сторінки правила
```

Очікувано: зелено; `rulewin.test.cjs` покриває вкладки (дубль, 6-та, закриття активної/останньої) і `place` (типове, збережене, поза екраном, мін/макс).

## Збірка й запуск

```bash
npx.cmd vite build -c vite.app.config.ts   # у desktop/src/ui/ має з'явитися rule.html
cd desktop && npm.cmd start
```

Якщо Q-Hub власника вже запущена — не `npm start`, а димова перевірка з підробленим electron (пам'ять `main-smoke-fake-electron`). Після збірки — перевірити, що в бандлі немає старих `.js`-копій замість `.tsx` (пам'ять `stale-js-copies-shadow-ts`).

## Ручна перевірка в грі (режим «вікно без рамки»)

| # | Дія | Очікувано | Вимога |
|---|---|---|---|
| 1 | Alt+Q → «зелена зона» → «Відкрити окремо» біля пункту | праворуч вікно «Правило» з пунктом: вид, номер, текст, покарання | FR-001, FR-002 |
| 2 | Alt+Q (сховати) | вікно лишилось; персонаж іде на WASD без кліку по грі | FR-003, FR-009, SC-001 |
| 3 | 10 кліків і перетягувань по вікну з закритою Alt+Q | вікно не рушить, кліки — у грі | FR-005, SC-002 |
| 4 | Alt+Q → тягнути заголовок, потім кут | рухається й міняє розмір; не менше ~280×160, не більше половини екрана | FR-004 |
| 5 | Закрити програму з трею, відкрити, відкрити пункт окремо | вікно на тому ж місці й розмірі, вкладок зі старого запуску немає | FR-006, SC-003, Clarifications |
| 6 | Відкрити окремо ще 2 пункти | одне вікно, 3 вкладки, остання активна; повторний той самий — без дубля | FR-007, SC-004 |
| 7 | Відкрити 6-й пункт | найстаріша вкладка зникла, коротка примітка | FR-007 |
| 8 | «×» на вкладках до останньої | вікно зникло | FR-008 |
| 9 | Пересунути вікно на другий монітор, від'єднати його, відкрити пункт | вікно праворуч на основному екрані | US2 #4 |
| 10 | Відповідь ШІ (Shift+Enter) | кнопки «Відкрити окремо» немає | Edge Cases |
| 11 | Шпилька плашки увімкнена | поки плашка видна — вікно можна рухати | Edge Cases |
