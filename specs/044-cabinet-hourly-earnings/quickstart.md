# Quickstart: перевірка «Заробіток за годину»

## Передумови

- Конституцію оновлено до 1.2.0 (принцип V) — без цього реалізацію не починати.
- Міграцію `supabase/migrations/0049_session_money.sql` застосовано на базі (вручну, див. пам'ять prod-migrations-gaps: перевірити, що 0043–0048 на місці).
- Сайт: `npx.cmd vite --mode production` (див. пам'ять dev-server-needs-production-mode).
- Програма: `cd desktop && npm.cmd start`, вхід через Discord, обраний персонаж.

## Автоматичні перевірки

```text
npm.cmd test                       # vitest: src/lib/earnings.test.ts
cd desktop && npm.cmd test         # node --test: sessionmoney.test.cjs, session.test.cjs
bash supabase/tests/run.sh         # session_money_test.sql
```

Очікування:
- `earnings.test.ts`: сеанс 23:30–01:30 за Києвом — у дні початку; Σ/Σ, а не середнє середніх; сумнівний і < 5 хв — у `skipped`; порожньо → `perHour = null`.
- `sessionmoney.test.cjs`: +100 000, −30 000, +50 000 → gain 150 000, net 120 000; стрибок +9 000 000 → flag, gain без змін; зміна персонажа → новий відлік.
- `session.test.cjs`: upsert двічі з тим самим `id` → один рядок; помилка фінального запису → підсумок у черзі, наступний tick зі зв'язком → черга порожня.
- `session_money_test.sql`: власник читає й пише свої `money_*`; інший `user`, `anon` і `admin` не бачать чужих сеансів; `money_rules` читає anon, змінює лише admin.

## Ручна перевірка (US1–US2)

1. Запусти гру з програмою, зіграй ≥ 10 хв, отримай гроші (зарплата, продаж скупнику), купи щось дешеве.
2. Закрий гру. За ≤ 1 хв відкрий `/kabinet/zarobitok`.
   - «Весь час»: зіграний час ≈ час від першого зчитування HUD; «Заробив» ≥ «Чистими».
3. Обери «Сьогодні» — один рядок дня з тими самими цифрами.
4. Вимкни інтернет посеред другого сеансу, закрий гру, увімкни інтернет, перезапусти програму — сеанс з'явився в кабінеті без дубля.
5. Увійди іншим акаунтом — вкладка показує лише його персонажів.

## Що не повинно змінитися

- Смужка Alt+Q показує прибуток поточного сеансу як раніше.
- `transactions` / `deals` — жодних нових рядків.
- Ціни, мапа, документи — без змін.
