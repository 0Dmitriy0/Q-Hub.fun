# Contract: вкладка кабінету «Заробіток»

**Адреса**: `/kabinet/zarobitok`; пункт меню кабінету «Заробіток» між «Документи» і «Налаштування». Персонаж — той, що обраний у кабінеті.

## Дані

Один запит:

```text
game_sessions
  select started_at, money_from, money_to, money_start, money_end, money_gain, money_flag
  where character_id = <обраний> and money_from is not null
  order by started_at
```

плюс `money_rules` (`min_minutes`). Розрахунок — `src/lib/earnings.ts`:

```ts
summarize(rows, { from?: Date, to?: Date, minMinutes }): {
  total: Day;            // підсумок проміжку
  days: Day[];           // лише дні з сеансами, новіші зверху
  best: string | null;   // day з найбільшим perHourGain
}
// Day = { day, ms, gain, net, perHourGain, perHourNet, skipped }
```

## Вигляд

1. **Весь час** (US1) — три числа: «Зіграно з програмою N год M хв», «Заробив X $ · Y $/год» (головне), «Чистими Z $ · W $/год» (менше, може бути з мінусом, червоним).
2. **Проміжок** (US2) — кнопки «Сьогодні / Тиждень / Місяць / Весь час» + поля «від — до»; за замовчуванням «Тиждень» (останні 7 днів за Києвом включно з сьогодні).
3. **Підсумок проміжку** — ті самі три числа.
4. **Графік** (US3, P3) — стовпчики «Заробив $/год» по днях проміжку.
5. **Таблиця днів** — дата, час, «Заробив», «$/год», «Чистими»; найкращий день позначено «Найкращий».
6. **Примітка під таблицею**: «День — за початком сеансу (київський час). Рахуються лише сеанси з програмою Q-Hub. „Заробив“ — усі надходження, зокрема перекази й продаж майна; „Чистими“ — різниця балансу з урахуванням витрат». Якщо є пропущені: «Не враховано N сеансів: коротші за 5 хв або з сумнівним зчитуванням».

## Стани

| Стан | Що видно |
|---|---|
| немає входу | як решта кабінету (вхід через Discord) |
| немає персонажа | «Додай персонажа в налаштуваннях» |
| немає жодного сеансу з грошима | «Ще немає даних — запусти гру з програмою Q-Hub» + посилання «Завантажити» |
| у проміжку немає днів | «За ці дні сеансів немає» (весь час лишається видно) |
| помилка мережі | «Не вдалося завантажити. Перевір інтернет і онови сторінку.» |

## Видалення (FR-016)

У таблиці днів не видаляємо; у «Налаштування» наявне видалення даних персонажа вже охоплює `game_sessions` (`OWN_TABLES`). Окремий сеанс — кнопка «Прибрати» в розгорнутому дні (рядок сеансу: час, Заробив, Чистими, позначка «сумнівне»).
