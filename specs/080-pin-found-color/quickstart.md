# Quickstart: колір стану форми Alt+F9

## Тести (агент)

```bash
npx.cmd vitest run src/desktop/pinStatus.test.ts
npx.cmd tsc --noEmit -p .
cd desktop && npm.cmd test
```

## Перевірка в грі (власник)

Збірка з гілки: артефакт `Q-Hub-Setup` з Actions або `cd desktop && npm.cmd start` (закрити свою Q-Hub).

| # | Дії | Очікування |
|---|---|---|
| 1 | Велика карта, масштаб 50–1500 м → Alt+F9 | Зелений блок «Нова мітка на мапі» з галочкою й координатами; зелена рамка знімка |
| 2 | Карта дуже віддалена → Alt+F9 | Червоний блок «Точку не знайдено» зі знаком уваги; причина читабельно; «Без точки мітку не надіслати. Наблизьте карту…»; червона рамка |
| 3 | Без великої карти (просто гра) → Alt+F9 | Червоний; підказка «Відкрийте велику карту…» |
| 4 | Світла тема плашки й прозорість 60 % | Обидва кольори помітні й текст читається |
| 5 | Скріншот форми → у чорно-білий | Стан зрозумілий за значком і заголовком (SC-002) |
| 6 | Enter / Esc / ↑↓ у формі | Як раніше |
