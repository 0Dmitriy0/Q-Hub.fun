# Contract: IPC `pin-ask` (головний процес → плашка)

`bar.webContents.send('pin-ask', { reason, preview, cats, point, player, kind })` — `kind` додано (data-model.md). Решта полів — без змін; стара плашка без `kind` працює як раніше (поле зайве), нова плашка без `kind` показує загальну підказку «Натисніть Alt+F9 ще раз».

## Що плашка показує (PinAsk)

1. Блок стану над полями: `ok` — зелений, значок-галочка; `bad` — червоний, значок-увага. Заголовок, рядок координат/причини, підказка — data-model.md, «Стан форми».
2. Знімок — рамка кольору стану.
3. Поля, кнопки, клавіші (Enter, Esc, ↑↓, Tab) — без змін.
