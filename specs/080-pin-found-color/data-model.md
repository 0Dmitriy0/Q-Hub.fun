# Data Model: Мітка Alt+F9 — колір стану

База не змінюється. Лише повідомлення між головним процесом і плашкою та похідний стан форми.

## Запит форми (`pin-ask`)

| Поле | Тип | Зміна |
|---|---|---|
| `point` | `{ x, y } \| null` | без змін — є: знайдено |
| `reason` | `string` | без змін — текст причини (порожній, коли знайдено) |
| `kind` | `'no_map' \| 'zoom_in' \| 'zoom_out' \| 'unsure' \| 'no_ref' \| 'error' \| null` | **нове**; `null`, коли точку знайдено; невідомий рядок плашка трактує як `error` |
| `player` | `boolean` | без змін — гравець (пропозиція) чи адмін (чернетка) |
| `preview`, `cats` | — | без змін |

## Стан форми (`pinStatus`)

- `tone`: `'ok'` ⇔ `point` є; інакше `'bad'`.
- `title`: `ok` + гравець — «Нова мітка на мапі»; `ok` + адмін — «Точку знайдено»; `bad` — «Точку не знайдено».
- `line`: `ok` — «X {x} · Y {y}»; `bad` — «Причина: {reason}».
- `help`: текст під рядком (research R2) — `ok`: наявні пояснення форми (без змін); `bad`: «Без точки мітку не надіслати.» + підказка (гравець) або текст про надсилання без точки + підказка (адмін).
