# Quickstart: перевірка глосарію

## Автоматично

| Команда | Що доводить |
|---|---|
| `npx.cmd vitest run src/desktop/rulesSearch.test.ts` | для кожного терміну початкового списку: кириличне скорочення, латинське й у не тій розкладці → ≥1 пункт (11 термінів); ГМ, БХ → картка, 0 пунктів; «33» → лише пункти 33, без картки; «зз», «pp» → картка ЗЗ і зелені зони; «дм у зз» → дві картки; «тк» → дві картки; `related_rules` — першими; наявні тести без змін |
| `npx.cmd vitest run src/lib/glossary.test.ts` | JSON = початкові рядки міграції 0080; кеш TTL 10 хв; без мережі — кеш, без кешу — JSON |
| `bash supabase/tests/run.sh` → `glossary_test.sql` | гість, `user`, `editor` → `42501`; `moderator`, `admin` зберігають, ховають, повертають, відкочують; кожна дія — версія; дубль назви → `23505`; ТК двічі з різними повними назвами — можна |
| `npm.cmd test`, `npm.cmd run typecheck` | усе зелене |

## Вручну

1. Конституція 1.4.0 закомічена (T001).
2. Міграцію 0080 накочено (власник, SQL з буфера).
3. Програма з коду (закрити Q-Hub власника → збірка → `cd desktop && npm.cmd start`): Alt+Q «дм» → картка ДМ і пункт ЗП 6.9 першим; «гм» → картка, «Окремого пункту в правилах немає»; «33» → пункт 33 без картки; «pp» → картка ЗЗ з підказкою «зз».
4. Сайт `/panel?tab=glossary` модератором: додати «НРД»-подібний тестовий термін → за ≤ 10 хв у плашці картка є; змінити пояснення → «Історія» → «Відкотити».
5. Сайт `/wiki/glosariy`: фільтр «вбив» → ДМ, ДБ, СК, ТК; клік на «РК» → пункти правил під ним.
