# Contract: смужка в режимі «скупник»

Програма (`main.cjs`) викликає `render(data)` у `strip.html`, як і зараз для сесії. Новий варіант даних:

```text
{ mode: 'buyer',
  buyer: 'Шкури',        // назва скупника для гравця
  read: 9,               // N — прочитано за це відкриття вікна
  total: 32,             // M — товарів скупника в Q-Hub
  pending: 2 }           // бачено, але ще не підтверджено (товари без меж) — для підказки
```

Вигляд (тексти дослівно):

| Стан | Текст |
|---|---|
| `read < total` | «Шкури: прочитано 9 з 32 — прокрути список, щоб дочитати» |
| `read < total`, `pending > 0` | те саме + « · 2 треба побачити ще раз» |
| `read === total` | «Шкури: 32 з 32 ✓» |

Правила показу:

- показується, коли вікно скупника відкрите довше 2 с, навіть якщо плашка Alt+Q закрита;
- не показується, якщо в налаштуваннях вимкнено «Ціни скупників на сайт» (`prefs().autoPrices === false`) або смужку
  вимкнено (`prefs().strip === false`);
- ховається через 35 с без кадрів із вікном скупника; якщо плашка відкрита — повертається режим сесії
  (`{ mode: 'session', ... }`, нинішні поля);
- оновлюється не частіше ніж раз на кадр розпізнавання; фокус не забирає, кліки проходять у гру (як зараз).

Відсутність `mode` = `'session'` (зворотна сумісність).
