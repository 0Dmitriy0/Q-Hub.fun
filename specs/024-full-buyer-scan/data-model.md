# Data Model: Усі ціни скупника (specs/024)

## Покриття вікна (лише в пам'яті програми)

| Поле | Тип | Опис |
|---|---|---|
| `buyer` | text | id скупника (`hide`, `junk`, …) |
| `openedAt` | ms | початок відкриття вікна (впізнали після паузи ≥ 30 с) |
| `total` | int | M — товарів скупника в каталозі |
| `read` | Set<item_id> | N — товари з підтвердженою ціною за це відкриття |
| `seen` | Map<item_id, price> | бачені, але не підтверджені (для товарів без меж — перша зчитка) |
| `lastAt` | ms | останній кадр із цим скупником |

Переходи: немає вікна → (скупника впізнано, паузи ≥ 30 с) → **відкрите** → кожен кадр оновлює `read`/`seen` →
(`now - lastAt ≥ 30 с`) → **закрите** (стан скидається).

Правила: `read` поповнюється, коли `pricePicker` підтвердив ціну (з межами — один кадр, без меж — дві однакові зчитки в
межах відкриття); `seen` не рахується в N.

## Рядок розпізнавання (`OcrLine`, `src/lib/shotParse.ts`)

| Поле | Зміна |
|---|---|
| `text`, `y`, `col` | без змін |
| `h` | **нове** — висота рядка в пікселях; рядки з `h < 0.7 × медіана колонки` відкидаються |

## `buyer_unknown_items` (нова таблиця, міграція 0029)

| Колонка | Тип | Правило |
|---|---|---|
| `id` | bigint identity | PK |
| `buyer_id` | text → `buyers.id` | обов'язково |
| `text` | text | 4–80 символів, розпізнана назва як є |
| `seen_count` | int | ≥ 1; повтор тієї ж пари (buyer_id, нормалізований text) збільшує лічильник |
| `last_seen` | timestamptz | час останньої зчитки |
| `reported_by` | uuid → auth.users | хто надіслав (default `auth.uid()`) |

Унікальність: (`buyer_id`, `lower(text)`). Права — у [contracts/buyer_unknown_items.md](./contracts/buyer_unknown_items.md).

## `buyer_items` (без змін схеми)

«Без меж» = `min_price` ≤ 0 або `max_price` ≤ `min_price`. Використовується для фільтра адміна на «Цінах».
