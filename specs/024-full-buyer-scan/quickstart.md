# Quickstart: перевірка specs/024

## Автоматичні перевірки

```bash
cd desktop && npm.cmd test          # pricescan: coverage, підтвердження в межах відкриття, записи з fixtures/prices
npm.cmd run test -- shotParse       # обрізані рядки (src/lib/shotParse.test.ts)
bash supabase/tests/run.sh          # buyer_unknown_items_test.sql (дозвіл і заборона)
```

Очікування:

- записи повного прокручування «Шкур» (32), «Мотлоху» (35), «Риби» (14) → `coverage` дає `M з M`, 0 хибних цін;
- запис без прокручування → `N < M`, підказка є;
- кадри з обрізаними рядками → ці рядки відкинуто, хибних цін 0;
- товар без меж, побачений один раз → не надіслано, `pending = 1`; двічі однаково за відкриття → надіслано.

## Перевірка в грі (`cd desktop && npm.cmd start`, гравець з персонажем)

1. Підійти до скупника «Шкури», відкрити вікно, не прокручувати → через ~2 с унизу екрана: «Шкури: прочитано N з 32 —
   прокрути список, щоб дочитати»; плашка Alt+Q при цьому закрита.
2. Повільно прокрутити до кінця → лічильник росте до «32 з 32 ✓».
3. Закрити вікно → смужка зникає за ≤ 35 с.
4. Вимкнути «Ціни скупників на сайт» у налаштуваннях → біля скупника смужки немає.
5. «Мотлох», швидке прокручування → товари без меж показуються як «треба побачити ще раз», доки їх не видно вдруге.
6. Журнал програми: жодного `prices …` з ціною поза межами скупника.

## Перевірка на сайті (адмін)

- «Ціни» → фільтр «без меж»: видно 6 товарів «Мотлоху» (на 2026-10-29); після заповнення меж — 0.
- «Невідомі товари у скупників» → з'являються назви, яких немає в каталозі; «Прибрати» видаляє рядок.

## Результати на живій грі (2026-10-29, «Шкури»)

- Кадр вікна скупника: ~5 с розпізнавання, ~7 с між кадрами (після пропуску розпізнавання меню; до того — 20–25 с).
- Смужка показується з першого кадру й не мерехтить; повільне прокручування — «32 з 32 ✓».
- 32 ціни на сайт, 0 поза межами. Знайдено й виправлено: «$» як «5» (51050 → 1050, 5546 → 546); ціна наступної картки
  прилипала до назви перед обрізаним рядком (423 замість 443).
- Ще не перевірено: зникнення смужки після закриття вікна (крок 3), вимкнення «Ціни скупників на сайт» (крок 4),
  «Мотлох» і «Риба».

## Відоме обмеження: короткі назви («Фугу», 2026-10-29)

На 75 кадрах «Риби» назву «Фугу» OCR жодного разу не впізнав («Eom», «Z=E om», «x= VY»), хоча ціну під нею ($353, ×30)
читав стабільно; власник підтвердив у грі, що ціна правильна. Програма таку ціну свідомо не приписує «останньому
непрочитаному» товару (принцип IV) — лічильник лишається «13 з 14». Ціну вносить гравець вручну.
