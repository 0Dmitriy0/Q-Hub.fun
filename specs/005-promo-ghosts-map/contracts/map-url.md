# Контракт: адреса мапи `/mapa`

| Адреса | Поведінка | Вимога |
|---|---|---|
| `/mapa` | Звичайні фільтри гравця, стартовий кадр | FR-009 |
| `/mapa?show=<category_id>` | Лише `<category_id>` + «Назви»; кадр на всі мітки категорії; параметр прибирається з адреси | FR-001, 002, 003*, 006, 007 |
| `/mapa?show=<id без міток або неіснуючий>` | Як `/mapa` | FR-008 |
| `/mapa?show=<id>#<координати>` | Лише категорія, але кадр — на точку з hash | (спекою не описано; поточна поведінка) |
| `/mapa#<координати>` | Без змін | FR-009 |
| `/mapa?game=1` | Без змін | FR-009 |

\* FR-003 у спеці зараз каже «стартовий вид», див. research R2.

**Стабільність**: значення `show` — це `map_categories.id`. Якщо адмін перейменує id, посилання з банера й ті, що вже поширили в Discord, тихо відкриють звичайну мапу. Тож id категорії, на яку веде банер, вважається публічним контрактом, поки банер живий.

**Джерело посилання**: `src/pages/Home.tsx`, банер `.h-promo` → `/mapa?show=pryvydy`.
