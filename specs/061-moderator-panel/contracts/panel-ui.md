# Contract: сторінки й поведінка панелі

Контракт інтерфейсу (адреси, хто що бачить, тексти). Права перевіряє база — цей контракт лише про показ.

## Адреси

| Адреса | Хто | Що |
|---|---|---|
| `/panel` | editor, moderator, admin | головна панелі: «Чекає на тебе» (mod, admin) + «Мої інструменти» |
| `/panel/rozbir?f=<фільтр>&id=<пропозиція>` | moderator, admin | розбір черги; `f` — `QueueFilter` (data-model), `id` — відкрита пропозиція |
| `/panel/rishennia` | moderator, admin | мої рішення |
| `/panel/prybrani` | moderator, admin | прибрані сторінки + заборони |
| `/admin`, `/admin?tab=…` | moderator | переадресація на `/panel` (`?tab=wiki` → `/panel/rozbir`) |
| `/panel…` | user, гість | «Не знайдено» (як `/admin` зараз) |
| `/panel/rozbir`, `/rishennia`, `/prybrani` | editor | переадресація на `/panel` |

## Шапка сайту

- editor, moderator: кнопка «Панель» → `/panel`; у модератора — число завдань на розгляді, якщо > 0.
- admin: кнопка «Адмінка» → `/admin` (без змін). На `/admin` угорі — посилання «Панель модераторів», на `/panel` — «Адмінка».

## `/panel` — головна

1. **Чекає на тебе** (mod, admin). Рядок на кожен вид із числом > 0, у формі «<число> <що> · найстаріша <давність>», клік → `/panel/rozbir?f=<вид>`. Окремий рядок «Конфлікти: N», якщо > 0. Черга порожня → «Усе розібрано. Нових пропозицій немає.» і посилання «Мої рішення», «Прибрані сторінки».
2. **Мої інструменти** (усі три ролі):
   - «Мої чернетки міток» — «На розгляді: N · Опубліковано: N · Відхилено: N» → `/mapa?tools=drafts`. Пояснення: «Мітки, які ти поставив у грі клавішею F9. Публікує власник.»
   - «Межі цін» → `/tsiny`. Пояснення: «Відкрий товар у скупника — під графіком поля „Мінімум“ і „Максимум“.»
   - «Івенти» → `/wiki/iventy`. Пояснення: «Додати чи змінити івент або промокод.»

Кожен розділ має заголовок і одне речення під ним (FR-007).

## `/panel/rozbir` — розбір

- Широкий екран: список ліворуч (вид, назва, автор, давність, позначка «Конфлікт»), відкрита пропозиція праворуч. До 720 px: або список, або пропозиція на весь екран з «← До черги».
- Список: до 50 найстаріших у фільтрі + «Ще N» текстом, якщо більше.
- Відкрита пропозиція, зверху вниз: що змінюється («було → стало» / нова сторінка / «сторінку буде сховано» / «точка застаріла» з міні-мапою) → автор: нік, «прийнято N, відхилено N» → джерело й скрін → дії.
- Дії (прилипають до низу картки): «Опублікувати» · «Підправити й опублікувати» · «Відхилити» (розкриває швидкі причини + поле своєї; без причини — підказка «Вибери причину — її побачить автор») · «Заборонити автору пропонувати» (другорядна).
- Конфлікт: «Поки ця правка чекала, картку вже змінили. Нижче — що зміниться поверх нової версії.» Кнопка — «Опублікувати поверх нової версії».
- Після рішення: відкривається `nextProposal`, угорі — «Опубліковано. Залишилось: N» / «Відхилено. Залишилось: N». Порожньо — «Усе розібрано» з посиланням на `/panel`.
- Скрін видалено / не відкрився: «Скрін уже прибрано» замість картинки.

## `/panel/rishennia`

Останні 50 рішень: дата, дія («Опубліковано», «Опубліковано з правками», «Відхилено: <причина>», «Відкат», «Прибрано», «Повернуто»), розділ, назва-посилання на картку (роботи — `/wiki/roboty?job=<id>`, мітки — мапа; транспорт — без посилання).

## `/panel/prybrani`

Наявні блоки «Прибрані сторінки» й «Заборони» з `AdminWiki` — без зміни поведінки, лише нові пояснення.
