# Quickstart: перевірка звірів на полях полювання

## Передумови

- Застосовано `supabase/migrations/0069_map_area_animals.sql` (вручну, див. пам'ять про пропуски міграцій).
- Для даних — `supabase/seed/map_hunting_animals.sql` (після відповіді власника на Q1) або позначити звірів вручну адміном.

## 1. Тести

```
npx.cmd vitest run src/lib/huntAnimals.test.ts
```
Очікується: точки всередині кожного з 6 контурів, без перетинів, детерміновані.

SQL-тест `supabase/tests/map_area_animals_test.sql`: anon і `user` не змінюють `animals`; `admin` змінює; `"wolf"` і повтор відхиляються check.

## 2. Сайт

```
npx.cmd vite --mode production
```
- Мапа → увімкнути «Поля полювання»: на полях з даними — ряд іконок звірів, підказка з назвою; картка поля містить список.
- Віддалити мапу: іконки не налазять на назви й мітки інших шарів (SC-005).
- Вимкнути шар — іконки зникають.
- Адміном: поле → «Змінити / перенести» → перемкнути звірів → зберегти → перезавантажити: зміна видна.

## 3. Мапа для гри

- Відкрити збирання мапи для гри, увімкнути «Поля полювання» → у попередньому перегляді на полях видно іконки звірів.

## 4. Програма

```
npm.cmd run build:app
cd desktop && npm.cmd start
```
(спершу закрити Q-Hub власника) — мапа в програмі показує те саме, що сайт. Запис у `changelog.json` у верхньому `pending`-паку.
