# Research: Тварини на полях полювання

## R1. Де зберігати звірів поля

- **Decision**: колонка `animals text[] not null default '{}'` у `public.map_areas` + check, що кожен елемент — один з 8 id.
- **Rationale**: поле полювання вже є рядком `map_areas`; RLS «read all / admin write» (0021) покриває колонку без нових політик; зміна видна без релізу (FR-006, FR-007).
- **Alternatives**: окрема таблиця `map_area_animals` (зайва для ≤ 8 значень і нових політик); звірі в `note` текстом (не перевіряється, не перекладається на іконки); жорстко в коді (потребує релізу — порушує FR-007).

## R2. Ідентифікатори видів

- **Decision**: `rabbit, cow, pig, coyote, deer, puma, panther, boar` — ті самі, що в `public/icons/meat/map.json` і `hide/`.
- **Rationale**: єдиний словник із м'ясом і шкірами; «Заєць» — підпис на мапі (у грі «кролик»).
- **Alternatives**: українські id — розходяться з наявними файлами.

## R3. Як малювати на мапі сайту

- **Decision** (уточнено під час реалізації): для кожного поля з непорожнім `animals` — **одна плашка** `L.marker` + `divIcon` `.manimal` у «внутрішньому центрі» поля (`animalSpots(ring, 1)`): світлий фон, рамка кольору категорії, іконки 20 px до 4 в ряд, `title` з назвами; клік відкриває картку поля зі списком. `zIndexOffset: -1000` — мітки інших шарів поверх. Шар категорії `hunting-fields` (вимкнений шар → немає звірів).
- **Rationale**: розмір плашки в пікселях сталий, тож на будь-якому зумі іконки не налазять одна на одну без перерахунку на кожен зум (FR-008, SC-005); світлий фон — щоб пантера й кабан читались на темній мапі.
- **Alternatives**: окремий маркер на кожного звіра з кроком у метрах (первинний план) — на дальньому зумі злипаються, на ближньому розлітаються; іконки лише в попапі (не видно з першого погляду — проти US1); фон-патерн у полігоні (нечитаємо).

## R4. Внутрішній центр поля

- **Decision**: центроїд полігона; якщо він поза контуром (увігнуті поля — поле 1 таке) — найближча до центроїда точка сітки всередині полігона (point-in-polygon, крок ~1/20 габариту). Ряд іконок розкладається горизонтально з кроком у метрах, що відповідає ~26 px на `LABEL_ZOOM`; іконки, що випали за контур, переносяться на наступний ряд.
- **Rationale**: проста детермінована логіка, легко тестується vitest без Leaflet.
- **Alternatives**: polylabel (зайва залежність для 6 полігонів).

## R5. Вибір звірів адміном

- **Decision**: у `MapAreaEdit` — набір кнопок-перемикачів з 8 іконками, показується, коли категорія зони — `hunting-fields`; зберігається в тому самому `update` разом із назвою/контуром.
- **Rationale**: без нового екрана; запис іде тим самим шляхом під RLS.
- **Alternatives**: окремий адмін-розділ — зайвий для 6 полів.

## R6. Мапа для гри

- **Decision**: у `GameMapExport` з `pickedAreas` з `animals` будуються додаткові `GamePin` (іконка `/icons/animals/<id>.svg`, колір категорії) у точках `animalSpots` з кроком під `iconM`; далі наявний конвеєр `buildGamePack`.
- **Rationale**: жодних змін у `gameMap.ts`; перегляд і архів беруть той самий список (US4).
- **Alternatives**: малювати іконки на текстурі окремим кодом — дублювання.

## R7. Стиль іконок

- **Decision**: SVG `viewBox 0 0 512 512`, як `icons/meat/*`: м'яка тінь-еліпс, силует голови/профілю звіра з градієнтом, контраст для світлої й темної теми. Розрізнення: пума — однотонна руда, пантера — чорна з жовтими очима; кабан — ікла й щетина, свиня — рожева з п'ятачком; заєць — довгі вуха; койот — гостра морда й сіро-рудий; олень — роги; корова — плями й роги.
- **Rationale**: FR-001/FR-002, SC-002; узгоджено з наявними іконками м'яса.

## R8. Розподіл звірів по полях (FR-011)

- **Decision**: у кожного поля свій набір (Q1 = A, 2026-11-16); список дає власник, сід пишеться за ним.
