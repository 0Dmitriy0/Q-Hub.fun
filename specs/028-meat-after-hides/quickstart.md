# Quickstart: перевірка «М'ясо — під шкурами»

## Автоматично

```sh
npx.cmd vitest run src/lib/subOrder.test.ts src/desktop/barSearch.test.ts
npx.cmd tsc --noEmit
```

## Сайт (SC-001, SC-003)

`npx.cmd vite --mode production` (без `--mode production` бази немає) → «Ціни»:

1. «Шкури», сортування «за назвою»: рядки 1–32 — шкури, далі підзаголовок «М'ясо», 8 рядків м'яса.
2. «Лише без меж» — м'ясо однаково нижче шкур.
3. «За ціною» / «найсвіжіші» / «вигідно» — один наскрізний список без підзаголовка.
4. Пошук «кабан» — шкури кабана вище, «М'ясо кабана» під підзаголовком.
5. «Риба», «Мотлох» та інші — без підзаголовків, порядок як раніше.

## Плашка (SC-002)

`cd desktop && npm.cmd start` → Alt+Q → «Ціни» → «шкури»:

1. Порожній склад: 32 шкури, потім 8 м'яса.
2. На складі «М'ясо оленя» і «Груба шкура кабана»: спершу шкура, потім м'ясо, далі решта шкур, далі решта м'яса.
